# Imbad0202/academic-research-skills 解读

## 基本信息

- **仓库**：[Imbad0202/academic-research-skills](https://github.com/Imbad0202/academic-research-skills)
- **Star**：★40,876
- **定位**：学术研究技能集——research → write → review 全流程，多语言支持（中/英/韩/繁中）
- **价值**：把学术研究从选题到发表的完整流水线编码为技能

## 4个技能详解

### 1. deep-research（深度研究，13-agent流水线）

- **触发**：研究、深度研究、文献综述、系统综述、meta分析、PRISMA、事实核查
- **核心**：**13-agent 流水线**做严谨学术研究——8种模式：完整研究、快速简报、论文审阅、文献综述、事实核查、三向文献扫描、苏格拉底式引导研究、系统综述（含可选meta分析）
- **覆盖**：研究问题表述、苏格拉底式指导、方法论设计、系统文献搜索、来源验证、跨来源综合、偏倚风险评估、meta分析、APA 7.0报告、编辑审查、魔鬼代言人挑战、伦理审查、研究后文献监控

### 2. academic-paper（学术论文写作，12-agent）

- **触发**：write paper、学术论文、guide my paper、AI disclosure、写论文
- **核心**：**12-agent 论文写作流水线**——11种模式（全文/规划/大纲/修订/修订教练/摘要/文献综述/格式转换/引用检查/披露/反驳审计）
- **覆盖**：6种论文类型、5种引用格式、双语摘要、LaTeX/DOCX-via-Pandoc/PDF输出
- **特色**：风格校准 + 写作质量检查 + 带IRON RULE标记的反模式

### 3. academic-paper-reviewer（多视角论文审稿）

- **触发**：review paper、同行评审、审稿、模拟审查、以审查人角度评估
- **核心**：**模拟5个独立审稿人**（期刊匹配审稿人 + 3个同行审稿人 + 魔鬼代言人），带领域特定专长
- **模式**：完整审稿、再审（验证）、快速评估、方法论聚焦、苏格拉底引导、校准模式

### 4. academic-pipeline（学术流水线编排）

- **触发**：学术流水线、研究到论文、完整论文工作流、research-to-publication
- **核心**：**10阶段端到端编排**——研究→写作→完整性检查→审稿→修订→再审→再修订→最终完整性检查→定稿
- **编排**：协调 deep-research、academic-paper、academic-paper-reviewer 三个技能
- **门禁**：强制完整性验证、两阶段同行评审、可复现质量门禁

## 与 Hermes 现有技能对比

| 维度 | academic-research-skills | Hermes现有 |
|------|------------------------|-----------|
| 深度研究 | deep-research（13-agent） | literature-review（单agent多源聚合） |
| 论文写作 | academic-paper（12-agent） | academic-paper-composer（逐章质量门控） |
| 审稿 | academic-paper-reviewer（5审稿人） | 无 |
| 编排 | academic-pipeline（10阶段） | plan（任务编排） |

**互补关系**：
- Hermes literature-review 侧重文献搜集→综述撰写；deep-research 是全流程研究（含meta分析）
- Hermes academic-paper-composer 侧重从大纲写全文；academic-paper 是12-agent完整流水线
- **academic-paper-reviewer 是 Hermes 完全缺失的**——模拟5审稿人审稿价值极高

## 可借鉴的提升点

1. **多agent流水线**：13-agent研究、12-agent写作、5审稿人评审——agent编排范式（Hermes delegate_task 可用时可借鉴，当前v0.16.0受限）

3. **IRON RULE 反模式标记**：写作质量检查的强制标记机制
4. **多语言触发**：中/英/韩/繁中多语言触发词设计
