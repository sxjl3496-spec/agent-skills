# 技能安装与迁移指南

> 从外部仓库（GitHub）把 Claude/Codex 技能迁移到 Hermes 技能库的完整流程。
> 本文档基于 2026-08-05 实际迁移8个技能的经验总结。

## 前置知识

### 技能本质

Agent 技能（Agent Skills）是模块化的指令包：每个技能一个目录，内含 `SKILL.md`（frontmatter 元数据 + 步骤指南正文）。agent 读 metadata 决定何时触发，触发后才加载正文，保持上下文精简。

```yaml
# SKILL.md frontmatter 标准格式（Hermes兼容）
---
name: 技能名          # 必填，决定触发名
description: 触发描述  # 必填，agent据此决定何时触发
license: ...          # 可选
metadata:             # 可选
  short-description: ...
---
# 正文：步骤指南
```

### 兼容性检查

| 字段 | 必要性 | 说明 |
|------|--------|------|
| name | ✅ 必填 | 决定技能名 |
| description | ✅ 必填 | 决定触发准确性（最重要） |
| license | ⚪ 可选 | 官方技能常带 |
| metadata | ⚪ 可选 | 部分平台用 |
| 其他自定义字段 | ⚪ 可选 | 兼容 |

**结论**：Claude/Codex 标准 SKILL.md 与 Hermes 完全兼容，直接复制即可。

## 迁移流程（5步）

### 步骤1：克隆源仓库

```bash
git clone --depth 1 https://github.com/<org>/<repo>.git   # --depth 1 只拉最新，省时
```

**批量调研技巧**：一次克隆多个仓库，放同一目录：

```bash
mkdir skills_research && cd skills_research
git clone --depth 1 https://github.com/obra/superpowers.git
git clone --depth 1 https://github.com/anthropics/skills.git
git clone --depth 1 https://github.com/openai/skills.git openai_skills
git clone --depth 1 https://github.com/composio-community/awesome-codex-skills.git
```

### 步骤2：定位技能目录

```bash
# Anthropic官方技能
ls skills/skills/                    # mcp-builder、frontend-design、skill-creator...
# OpenAI官方技能（.curated目录）
ls openai_skills/skills/.curated/    # figma-implement-design、figma-use...
# Composio社区技能（仓库根目录）
ls awesome-codex-skills/             # create-plan、gh-fix-ci、47个...
```

### 步骤3：复制到 Hermes 技能库

```bash
SKILLS_ROOT=<Hermes技能目录>

# 分类目录（development）
cp -r skills_research/skills/skills/mcp-builder "$SKILLS_ROOT/development/"
cp -r skills_research/openai_skills/skills/.curated/figma-implement-design "$SKILLS_ROOT/development/"

# 技能包（如Superpowers的14个子技能 → 新建分类）
mkdir -p "$SKILLS_ROOT/superpowers"
cp -r skills_research/superpowers/skills/* "$SKILLS_ROOT/superpowers/"
```

**目录结构**：`skills/<分类>/<技能名>/SKILL.md` + 可选 references/、scripts/、assets/

### 步骤4：验证 frontmatter

```bash
# 检查每个新技能都有 name + description
for d in skills/development/mcp-builder; do
  head -5 "$d/SKILL.md" | grep -E "^(name|description):"
done
```

### 步骤5：确认 Hermes 识别

```bash
hermes skills list | grep <技能名>
# 应显示 enabled 状态
```

## 常见坑

1. **仓库名冲突**：多个仓库都叫 skills → 克隆时指定目标目录（`git clone ... openai_skills`）
2. **深度限制**：--depth 1 看不到历史，需查历史用完整克隆
3. **分类选择**：Hermes 技能库按分类组织，新技能放 development/ 或新建分类
4. **依赖检查**：部分技能依赖外部工具（Figma MCP、gh CLI），安装时标注清楚
5. **版本更新**：定期 `hermes skills check` 检查官方技能更新

## 迁移到其他平台

本流程同样适用于向其他 agent 平台迁移技能：
- **Claude Code**：复制到 `~/.claude/skills/` 或插件市场
- **Codex**：复制到 `~/.codex/skills/` 或用 skill-installer
- **OpenCode**：插件系统或 `skills.paths` 配置
- 核心是 SKILL.md 的 frontmatter 兼容性，正文动作描述保持工具无关
