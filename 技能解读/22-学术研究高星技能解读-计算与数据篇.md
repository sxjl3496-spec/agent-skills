## 2. paper2code（arXiv论文转代码，★1,468）

- **仓库**：PrathamLearnsToCode/paper2code
- **触发**：`/paper2code <arxiv URL或ID>`、说"implement this paper"、粘贴arxiv链接要求实现
- **核心**：把 arXiv 论文转成**最小、引用锚定的 Python 实现**
- **模式**：minimal（默认）/ full / educational
- **框架**：pytorch（默认）/ jax / numpy
- **5阶段流水线**：
  1. paper_acquisition（论文获取）
  2. contribution_identification（贡献识别）
  3. **ambiguity_audit（歧义审计）**——诚实标注所有歧义
  4. code_generation（代码生成）
  5. walkthrough_notebook（讲解notebook）
- **guardrails（护栏）**：
  - badly_written_papers（论文写得很差时的处理）
  - **hallucination_prevention（防幻觉）**——绝不发明论文中未说明的实现细节
  - scope_enforcement（范围强制）
- **价值**：用户读论文→复现实验的核心工具；防幻觉护栏与 verify 证据先行呼应
