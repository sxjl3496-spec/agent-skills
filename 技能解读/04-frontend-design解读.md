# frontend-design 解读

## 基本信息

- **来源**：Anthropic 官方技能仓库 `anthropics/skills`（★166K）
- **官方描述**：Guidance for distinctive, intentional visual design when building new UI or reshaping an existing one
- **排行**：第4名（Vercel 出品标签）
- **定位**：告别 AI 默认丑 UI，一键出高级前端

## 核心哲学

> 把自己当作小型工作室的设计总监，客户已拒绝过"模板化"的方案，付费买的是独特视角：对调色板、字体、布局做出深思熟虑、有观点的选择，并承担一个你能论证的真实美学风险。

## AI 生成的三个"默认外观"（必须避免）

1. 暖奶油色背景（近 #F4F1EA）+ 高对比衬线展示字体 + 赤陶色点缀
2. 近黑色背景 + 单一亮酸绿/朱红点缀
3. 报纸式布局：发丝线、零圆角、密集报纸风多栏

> 三种都是合理选择，但它们是"默认值"而非"选择"。它们与主题无关地出现。简报锁定的方向要严格遵守；未锁定的轴不要浪费在默认值上。

## 设计原则

1. **Hero 是论文（The hero is a thesis）**：用主题世界中最有特色的事物开场（标题、图片、动画、演示、互动时刻），不用模板答案（大数字+小标签+支撑数据+渐变点缀）
2. **字体承载个性**：刻意搭配展示体和正文字体，建立清晰的字体阶梯（type scale），让字体处理本身成为设计的记忆点
3. **结构即信息**：编号、眉题、分隔线、标签应编码关于内容的真实信息，而非装饰。问"编号标记（01/02/03）真的有意义吗？"——只有当内容确实是序列时才用
4. **刻意运用动效**：页面加载序列、滚动触发揭示、悬停微交互、氛围动画。编排的时刻比散落效果更有效。有时更少就是更多——过度动画让设计显得AI生成
5. **复杂度匹配愿景**：极繁方向需要精细执行；极简方向需要精确间距、字体、细节
6. **文案是设计材料**：复制文案本身就能让设计显得模板化。从用户视角命名事物，用主动语态，错误不道歉且不模糊，空屏幕是行动邀请

## 两遍工作法（Process）

**第一遍：头脑风暴设计计划**
- 基于简报创建紧凑 token 系统：色彩（4-6个命名hex值）、字体（2+角色：有个性的展示体+互补正文字体+工具字体）、布局（一句话散文描述+ASCII线框图）、签名元素（本页被记住的独特元素）

**第二遍：对照简报批判后再构建**
- 任何部分读起来像"任何类似页面的通用默认"→ 修改并说明改了什么、为什么
- 确认设计计划相对独特性后才开始写代码，严格遵守修订后的计划，每个颜色和字体决策都源于它

## 克制与自我批判

- **在一个地方挥霍大胆**：让签名元素成为唯一被记住的东西，其他保持安静自律
- **质量底线不宣布**：响应式到移动端、可见键盘焦点、尊重减少动效偏好
- **构建中自我批判**：环境支持就截图（一图胜千言）
- **香奈儿建议**：出门前照镜子，摘掉一件配饰

## 可借鉴的提升点

1. **反AI模板清单**：三个"默认外观"列表直接可用，任何UI生成前先自查
2. **Token系统方法**：色彩/字体/布局/签名四要素设计计划
3. **两遍工作法**：设计→批判→再构建，防止一次性产出模板货
4. **文案设计化**：把文案当作设计材料对待
