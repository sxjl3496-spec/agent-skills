# 学术研究高星技能解读（投稿与格式篇）

> 用户（吉首大学科研人员）专项调研。本文档为「期刊投稿/学术格式校准」维度解读。

## 1. paperjury（投稿前对抗审稿，★875）

- **仓库**：u7079256/paperjury
- **触发**：review/critique/审稿/评审/mock-review；改这段/把中文想法写成latex/polish/de-AI/translate/compress
- **核心**：**CS会议论文**（CVPR/ICCV/ECCV视觉、ACL/EMNLP/NAACL NLP、ICLR/NeurIPS/ICML/AAAI ML）的编辑和加固
- **三种模式**：
  - **DIRECT-EDIT模式**（常见）：用户描述修改（中英文均可），通过CS会场写作工具包直接编辑LaTeX/Markdown，作者签署确认
  - **REVIEW模式**（投稿前）：对抗式法庭审查引擎——N个整体领域审稿人 → 可争议性路由 → 双面审判 → 三方裁决 → 书记员收敛多轮循环；每项修改需共识门控+作者签署；问题跟踪持久台账
  - **AUTO模式**（无人值守）：向可验证目标运行审查-修订循环，漂移受限策略下应用安全修复，高风险项排队等人工
- **全通用设计**：无硬编码路径，所有论文特定信息（手稿位置/会场/签署人/风格）运行时解析
- **价值**：投稿前找审稿人痛点——比 Hermes academic-paper-reviewer 更聚焦 CS 会议（含CVPR/NeurIPS等），且带**共识门控修改**机制

## 2. journal-adapt（期刊写作惯例学习，★738）

- **仓库**：WantongC/journal-adapt-writing-skill
- **触发**：想把论文适配到目标期刊、构建语料库写作技能、逐节按期刊和领域写作信号修订
- **核心**：**动态学术写作技能生成器**——结合可选静态写作技能 + 目标期刊语料库 + 领域顶级/主题相似参考论文 + 用户/实验室范例，为单篇手稿构建**临时、可审查**的写作技能
- **两阶段**：Phase 1 读取参考论文（只输出结构和修辞描述，**绝不引用/转述/复现发现**）→ Phase 2 逐节修订（一次一节）
- **HARD RULES**：
  1. 绝不添加事实（不引入原手稿没有的新经验主张/结果/引用/数据）
  2. 绝不改变技术内容（公式/LaTeX命令/引用键/变量名/模型符号/数值结果/命题/脚注逐字保留）
  3. 绝不转述语料库论文
  4. 一次一节
- **价值**：用户投稿时先学目标期刊写作惯例再改写——比通用润色更精准；"学期刊→改论文"的闭环设计精妙
