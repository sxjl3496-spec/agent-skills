# 学术写作流程实战（论文 74.5→97 分方法论）

> 主题论文《某主题论文》从骨架到可投稿的完整方法论（某期刊投稿版）。
> 适用：科研论文/项目申请材料/综述的 Agent 辅助写作。

## 一、反向提纲（写正文前必做）

**主张-证据映射表**：每节=若干"一段一信息"单元，每段写清：
- **主张（Claim）**：这段要证明什么（一句话）
- **证据（Evidence）**：支撑主张的数据/文献/实验记录（可追溯）

实战案例（论文 N 个单元）："某结果复现（多组条件实测值）"→证据=实验记录_多组重复_日期.json（Figure 某图）——每个主张都有落点。

## 二、一段一信息（写作执行）

- 每段 1 主张 + 2-3 证据句，不写铺垫句/升华句
- 删除无信息量的过渡（"值得注意的是""不难发现"）
- 具体数字替代空泛程度词

## 三、主张-证据对齐（写完后自查）

逐段反向检查：删掉证据句后主张还成立吗？删掉主张句后证据段有意义吗？——双向依赖才合格。

## 四、对抗自审（paperjury 式双面审判）

**正方**：每节主张→证据追溯表核对（全部有据）
**反方**：找无证据主张/夸大表述/机制漏洞/表格错误：
- 实战发现并修正：表格某比率行定义错误（数值→修正值）、某指标最小值与实测不符（记忆值→实测值）、引用语境错位 K 处

## 五、复制粘贴硬伤专项检查（终审高频项）

1. 重复句（同句出现两次）——grep 相同长句
2. 序号重复（两个"Fourth"）——编号连续性扫描
3. 占位符残留（[AuthorYear] 未转编号）——正则全稿扫描
4. 旧值回归（修正过的值又出现旧版）——对照核实版全量 diff

## 六、数据真实性铁律

- 正文所有数字必须能从实验记录/存档 JSON 复核（某实测值案例）
- 图件与正文数据同源（统一数据源）
- 声明"robust/verified"必须有存档证据

## 七、多角色协作流水线（本团队配置）

写作 Agent → 审核 Agent（逐章审核+评分卡）→ 终验 Agent（终验+亲自润色）→ 双独立评委（独立判定）→ 修复循环至达标
