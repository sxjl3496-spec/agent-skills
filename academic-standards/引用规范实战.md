# 学术引用规范实战（51 篇文献零编造战役方法论）

> 2026-08-07 假文献危机后沉淀：申报书 52 篇参考文献查出 7 篇疑似编造 + 30 余处卷期页码错误 → 全员技能包 + 本实战方法。
> 适用：任何需要引用文献的 Agent 任务（申报书/论文/综述）。

## 一、铁律（违反即返工）

1. **禁止编造**：查不到 → 删除或替换，绝不臆造
2. **禁止"待核实"**：交付物不允许出现该字样——信息不全=不合格
3. **双重验证**：英文 Crossref（DOI 或标题检索）、中文 PDF 原文/知网题录
4. **编号对应**：列表编号与正文引用一一对应，无悬空、无跳号
5. **作者名以 Crossref family 字段为准**——禁止凭搜索结果推断（实战教训：Zhou Yan/Zhao Yuan 实为 YAN Z/YUAN Z，名序推断致错）

## 二、英文文献：Crossref API 标准流程

```python
import requests
session = requests.Session()
session.trust_env = False  # 必须：绕过系统代理

# 方式1：按DOI精确验证（最可靠）
r = session.get(f"https://api.crossref.org/works/{doi}", timeout=20)
# 200=存在，404=疑似编造

# 方式2：按标题+作者检索
r = session.get("https://api.crossref.org/works", params={
    "query.bibliographic": "论文标题关键词",
    "query.author": "作者姓", "rows": 3,
    "select": "DOI,title,author,container-title,volume,issue,page,published"}, timeout=25)
```

**判定**：完全匹配→采用 Crossref 信息（以官方为准修正）；无匹配→疑似编造；部分不符→以 Crossref 为准。

**常见坑**：
- 经典文献（Coase 1960 等）Crossref 收录不全 → 用公认标准信息
- 检索返回噪音（第一条不匹配）→ 加 `query.container-title` 限定期刊
- 中文期刊 Crossref 覆盖不全 → 走 PDF 验证

**页码提取技巧**：
- 页脚数字可能是 `·N·`、`-- N`、全角数字、左右分列（个位/十位反序）
- 无卷号期刊（科技管理研究/重庆社会科学）：只标 年(期): 页码
- 主稿元数据不可信——**逐篇 PDF 核实**（实战教训：13 篇中文页码主稿全错，PDF 核实后全部修正）

## 四、GB/T 7714 要点

| 类型 | 格式 |
|---|---|
| 期刊 [J] | 作者. 题名[J]. 刊名, 年, 卷(期): 起始-结束. |
| 专著 [M] | 作者. 书名[M]. 出版地: 出版社, 年. |
| 章节 [M]// | 作者. 章节名[M]//书名. 出版地: 出版社, 年: 页码. |
| 会议 [C] / 报告 [R] | 可省略页码（合规） |

作者 3 人内全列，超 3 人前 3+et al.；英文姓全大写。

## 五、引用语境匹配（审稿人必抓项）

正文引用处语境必须与文献主题一致，三类高频错误：
1. **方法错位**：DID 语境引 ABM 综述（Heckbert 案例——已删改引）
2. **主题错位**：价格稳定机制语境引 EPU 论文（Li 案例——已调整表述）
3. **行业错位**：钢铁示例引电力模型（Liu 案例——已删引用）

**审查流程**：每处引用提取前 40 字语境 → 与文献主题比对 → 不匹配即处理（改引/删引/调整表述）。
