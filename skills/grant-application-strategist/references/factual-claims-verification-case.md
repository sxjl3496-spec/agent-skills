# 申报书事实性制度主张查证案例：环保税申报表字段

> 2026-08-13 省自科申报书"税收数据驱动"命门论证的查证实战。申报书中引用制度细节（申报表字段/法规条款）前必须查证，不能凭常识。

## 背景

申报书核心创新"基于法定税收数据的减排效率测度"依赖一个事实主张：**环保税申报表同时提供销售额（分子）与排放量（分母）**。若该字段不存在，"税收数据驱动"的全部论证（一个口径双数据、跨部门交叉验证）被击穿。

## 质疑来源

Claude Code评审V4时指出：
> "环保税申报表（A表）字段为排放量、污染当量数、适用税额、应纳税额、减免税额等，不含'销售额'；销售额在增值税申报表。环保税'排污系数法'核算附表确实填报产品产量/原辅材料用量（用于换算排放量），但那是'产品产量'而非'销售额'。"

## 查证过程（web_search）

1. 搜索"环境保护税纳税申报表 A表 填报项目 字段 污染物排放量 产品产量 销售额"
2. 命中上海税务局官网申报表文档 + 税屋解读：
   - A表主表（适用于自动监测/监测机构监测/排污系数法/物料衡算法）：第11栏"污染物排放量"、第14栏"单位税额"等——**无销售额字段**
   - 附表（排污系数法）：**"计算基数"栏填写产品产量值或原材料耗用值**（用于排放量换算）
3. 结论：Claude Code质疑**一半正确**——主表无销售额，但附表有"产品产量"（可经行业平均价格近似产值）

## 修复后的正确表述

> "环保税申报表**主表**填报污染物排放量（分母），**排污系数法附表'计算基数'**填报产品产量（经行业平均价格可近似产值，作分子），同一纳税人主体跨税种匹配；增值税销项税额提供销售额交叉验证。"

## 规则

1. **申报书中引用的制度细节（申报表字段/法规条款/程序要求）必须查证**——尤其当它是核心创新的数据基础时
2. **标题级卖点把最脆弱的事实主张推到聚光灯下**：标题承诺了最强版本（如"税收数据驱动"），正文必须扛得住
3. **区分"主表"与"附表"**：很多数据在附表中（排污系数法附表"计算基数"），不能因主表没有就断言"申报表不含X"
4. 查证修正后**全文同步检查同源表述**：本案例2.1信息不对称破解、创新点1、4.2数据清单三处都要改，漏一处就留一个事实错误
5. **保守表述优于夸大**：不确定字段是否存在时，用"依托XX数据共享协议获取"（实施前提）比断言"申报表含X字段"安全
