# 多Agent审查案例：3视角并行评审 + 8项修订

> 案例：2026.8.1 湖南省自科基金青年A类申报书审查
> 3个agent并行运行，共返回21项评分+15条修改建议，整合后采纳8项

---

## 3位评委评分汇总

| 评委 | 视角 | 综合评分 | 最关键建议 |
|:---|:---|:---:|:---|
| A | 应用数学/运筹学 | 3.1/5 | 补齐MILP数学形式化+构建协同优化双层规划框架 |
| B | 系统科学/仿真方法 | 3.0/5 | 补全微观交通流模型(IDM/MOBIL)+修正MATSim对比+补全统计设计 |
| C | 交通工程/计算科学 | 2.5/5 | 明确路网规模+补充OD数据来源+落实合作团队 |

## 评委A核心发现

1. **MILP目标函数模糊**：未给出决策变量(δᵢ)、目标函数(Σwᵢⱼ)、约束集合的代数表达
2. **通篇未提及变分不等式(VI)**：出行权交易均衡分析的标准数学工具缺失
3. **协同只是"并列评估"**：内容二(绿波)和内容三(出行权)独立建模后简单叠加，非真正协同
4. **参数校准最扎实**（4/5）：贝叶斯优化+LHS体系完整，但损失函数形式和高维降维需补

## 评委B核心发现

1. **缺微观交通流模型**：提到"跟驰/换道"但未指明IDM/MOBIL等标准模型
2. **MATSim对比不准确**："尚未被实现"的论述会被交通专家质疑
3. **统计实验设计完全缺失**：无重复次数/warm-up/敏感性分析方法
4. **市场行为只是文字描述**：非可计算的决策规则

## 评委C核心发现

1. **"大规模路网"定义模糊**：未量化路口数量(建议明确20-30个)
2. **OD矩阵来源不明**：ABM仿真的核心输入未说明
3. **忽略实际约束**：行人过街/公交优先/时变配时等
4. **400km距离**：吉首大学距长株潭太远，实地数据获取困难

## 最终采纳的8项修改

| 修改项 | 对应评委 | 修改内容 |
|:---|:---:|:---|
| 1 | A | MILP完整数学形式化：决策变量δᵢ、目标函数Σwᵢⱼ、约束集合、可解性说明 |
| 2 | A+B | 微观交通流模型：IDM跟驰+MOBIL换道+三层行为架构 |
| 3 | A | 理论对照基准：VI形式的UE+Frank-Wolfe算法作为ABM对照 |
| 4 | B | 仿真实验统计设计：重复≥30次+Sobol敏感性+Morris筛选+warm-up |
| 5 | B | MATSim对比修正：删除"尚未被实现"，改为"差异化定位" |
| 6 | C | OD数据来源：手机信令反推+OSM车道级+BPR阻抗函数 |
| 7 | C | 路网规模明确：长沙市中心城区20-30个干线路口 |
| 8 | A | 损失函数数学形式：φ(θ)=Σwᵢ·‖f_sim(θ)-f_obs‖₂ |

## 未采纳的建议及理由

| 建议 | 来源 | 未采纳理由 |
|:---|:---:|:---|
| 双层规划(Bi-level)统一框架 | A | 3年内实现难度大，青年基金不宜过度承诺 |
| 提炼数学定理(均衡存在性) | A | 超出申请人理论能力范围 |
| 收窄到1-2条走廊 | C | 会削弱"长株潭都市圈"战略对接 |
| DRL替代GA | A | 申请人无DRL经验 |

## 经验教训

1. **delegate_task在v0.19.0可用**：3个agent全部成功返回（qwen3.7-flash模型），未触发401 bug
2. **3视角评审远超单一审查**：Claude Code单次审查评分3.40/5，3视角评审发现了Claude Code未发现的问题
3. **评审意见整合需要取舍**：不是所有建议都采纳，需评估实施成本和对成功率的边际贡献
