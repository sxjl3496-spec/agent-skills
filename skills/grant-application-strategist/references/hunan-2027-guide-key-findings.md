### 吉首大学联合基金

申报指南第13页：
> 吉首大学联合基金项目：支持吉首大学及与其开展合作的科研机构，聚焦武陵山片区特色资源开发与文化传承等重点领域

设置：重点项目（50万）+ 一般项目（5万）+ 大学生护航项目（10万）

**注意**：吉首大学联合基金方向限"武陵山片区特色资源开发与文化传承"，与经济科学/碳交易方向不匹配。省教育厅联合基金方向不限，更适合。

## 限项规定（毕业制）

### 申报数量限制

- 当年申请（含参与）省自科各类项目总数不超过**2项**
- 只能作为申请人申请**1项**
- 有在研项目（面上/C/D/联合基金）的可申请A类或B类

### 毕业制规则

| 获得过 | 不能再申请 |
|:---|:---|
| 青年D类 | D类 |
| 青年C类 | C类、D类 |
| 面上 | 面上、C类、D类 |
| **青年B类** | **B类、面上、C类、D类**（A类不受限 ✅） |
| 青年A类 | B类、面上、C类、D类 |
| 重点项目 | 重点、B类、面上、C类、D类 |
| 创新群体 | 所有类型 |

### 申请代码填写规则与 G0314 核实（2026-08-07 实测）

- 指南原文（附件1）：申请代码**必须选到最后一级（4位数字）**；代码1是遴选评审专家的依据，代码2作补充
- G03 资助范围明确包含**资源与环境经济**领域（碳交易课题对口）
- 附件1 重点项目立项领域第81条为 `基于多模态大数据的环境规制分析与政策优化设计(G0314)` —— G0314 编号在指南中确认存在，方向与碳交易环境规制高度吻合
- **碳交易课题建议**：代码1 = G0314（资源与环境经济），代码2 = G01（管理科学与工程）；最终以湖南科技云平台填报时的代码下拉列表为准（md 转写稿不含完整代码目录表）
