# 学科归属定位：省自科 vs 省社科（2026.8.1 案例）

## 核心问题

同一个研究课题（交通拥堵+ABM仿真+出行权交易）可以被归入不同学科。选错学科可能导致：
1. 学科代码找不到对应的（省自科可能没有管理科学代码）
2. 评审专家认为"这是社科课题，不该来自科"

## 判断框架

### 步骤1：判断课题的核心是什么

| 课题核心是... | 归属学科 | 能否申请省自科 |
|:---|:---|:---|
| 经济学理论（福利/公平/行为） | 社会科学 | ⚠️ 有风险 |
| 数学方法（仿真/优化/建模） | 应用数学 | ✅ 安全 |
| 交通工程（信号/路网/流理论） | 工程科学 | ✅ 安全 |
| 跨学科（数学+经济+运筹） | 交叉学科 | ✅ 公告"促进跨学科交叉" |

### 步骤2：语言转换

同一研究内容可以用不同学科语言表述：

| 研究内容 | 社科表述（避免） | 自科表述（采用） |
|:---|:---|:---|
| ABM仿真 | 行为响应仿真 | 异质性智能体动力学建模 |
| 绿波优化 | 助推效应 | 混合整数规划与协同优化 |
| 出行权交易 | 福利分配 | 机制设计的数学建模 |
| 政策评估 | 分配公平分析 | 反事实实验与绩效比较 |
| 市场均衡 | 帕累托改进 | 变分不等式求解 |

### 步骤3：确定申请代码

- **国自然**：有G学部（管理科学），经济学/管理学可以正常申请
- **省自科**：各省政策不同，需要确认是否有管理科学代码
  - 如有G类代码：可以偏经济学
  - 如无G类代码：必须以A（数理科学）申请，申报书必须用数学语言

## 本案例最终定位

**课题**：基于多智能体仿真的城市交通拥堵治理：信号优化与出行权交易的协同机制研究

**定位策略**：以"方法"为核心，经济学为应用背景

| 维度 | 定位 |
|:---|:---|
| 核心卖点 | ABM仿真方法+网络优化+机制设计（数学） |
| 经济学理论 | 作为应用背景出现，不是主线 |
| 学科归属 | 应用数学/交叉学科 |
| 申请代码 | A（数理科学）或 G（如湖南省有管理科学代码） |
| 关键词 | 多智能体仿真；混合整数规划；交通拥堵；机制设计；网络优化 |

**三个合作者的学科链**：
- 冯泽宇：经济学（福利分析+行为建模+计量）→ 申报人
- 孟开文：运筹学（优化理论+市场均衡+变分分析）→ 项目组成员
- 欧祖军：统计学（实验设计+参数校准）→ 项目组成员

形成"经济学+数学+运筹学"交叉团队，但申报书主线是**数学方法解决复杂系统问题**。

## 省自科 vs 国自然的关键差异

| 维度 | 国自然 | 省自科 |
|:---|:---|:---|
| 管理科学部 | 有（G学部） | 各省不同，部分省无 |
| 经济学方向 | 可正常申请 | 需确认是否有对应代码 |
| 区域偏好 | 无 | 强偏好本省战略需求 |
| 学科交叉 | 鼓励 | 公告原文"促进跨学科交叉融合发展" |

**结论**：申报省自科时，宁可偏数学也不要偏经济学。经济学理论可以作为应用背景，但学科归属和关键词必须落在数理科学上。
