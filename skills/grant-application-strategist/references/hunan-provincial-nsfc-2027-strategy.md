## 七、调研中遇到的技术问题

### Web搜索工具的局限性

- **百度搜索**：通过 Python requests + `session.trust_env = False` 绕过代理后，搜索结果HTML解析效果差（可能是JS渲染）
- **Google搜索**：通过 Clash 代理（端口7897）访问，HTML解析同样效果差
- **Bing搜索**：同样效果差
- **GitHub API**：✅ 可靠，`curl -s "https://api.github.com/search/repositories?q=KEYWORD&sort=stars"` 可获取结构化JSON数据

**结论**：Web搜索引擎的HTML解析不可靠，GitHub API 是获取开源项目信息的可靠途径。对于政府网站信息（申报指南详细内容），需要用户自行登录平台查看。

### vision_analyze 用于扫描版PDF

- **PDF直接传给 vision_analyze**：❌ 不识别（"source is not a recognized image"）
- **PyMuPDF 渲染为PNG后传给 vision_analyze**：✅ 成功（2026.8.1 实测：3页扫描版简历PDF→PNG→vision_analyze 提取全部论文信息）
- 关键代码：`import fitz; doc = fitz.open(pdf_path); page = doc[i]; pix = page.get_pixmap(dpi=200); pix.save(out_path)`
