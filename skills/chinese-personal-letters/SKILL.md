# Chinese Personal Letters with Classical Literary Framing

## Core Principle

**真心为骨，古文为衣。** Classical literary forms (圣旨、出师表、诗词) provide structure and dignity, but the content must be raw, honest, and personal. Never let theatrical language drown out sincerity.

## User Preference: Offer Versions When Emotionally Blocked

When user is emotionally resistant to writing (没心情写、满脑子只有吐槽), don't just produce one draft. **Write the first draft yourself, then let user react and guide revisions.** The iterative process IS the therapy — each round the user sees their own feelings reflected back in better words, and gradually opens up.

## Critical Workflow: Iterative Drafting

This type of writing **always** requires multiple rounds. Do NOT aim for a perfect first draft.

1. **First draft**: Write based on what user shares. Present full text.
2. **User correction round(s)**: User will correct persona, tone, scope, details. Expect 3-5 rounds. Each correction is a signal, not a complaint.
3. **Final polish**: Small adjustments to specific sections, not full rewrites.

**Never say "this is the final version"** — let the user decide when it's done.

## The Sincerity Spectrum (Key Pitfall)

When using classical forms, there's a trap of going too theatrical:

```
TOO HUMBLE          SWEET SPOT              TOO THEATRICAL
(跪着写)           (站着说真心话)            (演戏)
臣、犬马、伏惟    用户/我、坦诚陈情          朕、天下、江山、太宗
```

**Lesson learned**: User explicitly corrected away from over-the-top imperial language (太宗、天下、江山 everywhere). The classical form should frame the letter (开头收尾定调), not saturate every sentence. Content = 出师表 sincerity. Format = 圣旨 authority.

## Persona Calibration

Users may want a specific self-reference persona (e.g., 用户, 某某). Rules:

- **Ask or infer** the persona from context — don't default to 臣/我
- **Alternate variants** for flow: use shorter form for rhyming/smooth passages, full form for emphasis (e.g., "帅" for flow, "用户" for gravitas)
- **Never impose humility** — if the user identifies as a warrior/leader, write from that seat

## Integrating Philosophy and Poetry

When user mentions idols or literary influences (毛主席, 李世民, 古诗词):

- **Quote the SPIRIT, not the words** — User explicitly corrected: "用毛主席诗词风格就好，不需要生搬"
- Write original lines that capture the same energy (乐观、魄力、不屈)
- Exception: if user specifically asks for direct quotes, then use them

**Bad**: 毛主席说过"雄关漫道真如铁，而今迈步从头越"……
**Good**: 前路纵有万重山，用户一双铁脚板，踏遍坎坷自向前。

## Real-Life Anecdotes > Abstract Promises

The most powerful moments in personal letters come from specific, true details:

- **"徒步登顶峨眉山，费时18小时"** → turned into "认准了山顶，就只管迈腿"
- **"2018年在快递站搭讪"** → became the origin story of the relationship
- **"父亲中风偏瘫"** → grounded the hardship in reality, not abstraction

**Always ask**: Does the user have a specific real experience that illustrates this point? Use it instead of a generic statement.

## Structure: 出师表 Template

The 凼师表 structure works for most personal letters about hardship + commitment:

1. **陈情** — Honest account of current situation and past hardship
2. **言志** — Concrete plans with verifiable milestones (not vague promises)
3. **表心** — Emotional core: why this person matters, what they've sacrificed
4. **结语** — Strong closing: brief, powerful, forward-looking

Each section should transition naturally. The letter should read as one continuous voice, not four disconnected essays.

## Handling Emotional Blockage

When user says "没心情写" or "满脑子只有吐槽":

- **Acknowledge the pain first** — don't jump to "let me help you write"
- **Reframe the blockage as material** — frustration, pressure, and hardship ARE the letter's content
- **The letter doesn't need to be happy** — 出师表 itself is full of difficulty and worry. Honesty about struggle is more compelling than forced romance.

## Common Pitfalls

- **Don't force 情话 when the user is in pain** — write from where they actually are emotionally
- **Don't compare to other people's relationships** in the letter unless user explicitly wants it
- **Don't add details the user hasn't shared** — if they mention a breakup rival but say "不要提", remove it completely
- **Don't make promises the user can't verify** — prefer "每一步有记录可查" over "我一定会成功"
- **圣旨格式**: 开头"奉天承运皇帝诏曰" + 结尾"钦此"定调即可，正文回归真心话
- **Length**: Personal letters can be long (出师表 is ~700字). Don't arbitrarily shorten.
