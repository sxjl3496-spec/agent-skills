# /aigc-check - AIGC 检测与改写建议

## 用途

检测文本中的 AI 生成痕迹，提供具体的改写建议，帮助论文降低 AIGC 检测率。

## 使用方法

```
/aigc-check [文件路径或文本]
```

## 检测标准

### 高风险表达模式

| 模式类型 | 典型表达 | 风险等级 |
|----------|----------|----------|
| 工整排比 | "首先...其次...再次...最后" | 🔴 高 |
| 模板插入语 | "值得注意的是"、"需要指出的是" | 🔴 高 |
| 机械化总结 | "综上所述"、"总而言之" | 🔴 高 |
| 空泛评价 | "具有重要意义"、"深远影响" | 🟡 中 |
| 套话视角 | "从...角度来看"、"基于...视角" | 🟡 中 |
| 过度解释 | "换句话说"、"也就是说" | 🟡 中 |
| 万能连接 | "此外"、"另外"、"同时" | 🟢 低 |

### 检测维度

1. **句式结构**: 过于工整的并列句、排比句
2. **词汇选择**: 模板化、套话式表达
3. **逻辑连接**: 机械化的过渡词使用
4. **内容深度**: 空泛评价缺乏实质内容
5. **语言风格**: 过于正式或缺乏个性

## 输出格式

```markdown
## AIGC 检测报告

**文件**: [文件名]
**检测时间**: [时间]
**风险等级**: [高/中/低]

### 问题汇总

| 位置 | 风险等级 | 原文 | 问题类型 | 改写建议 |
|------|----------|------|----------|----------|
| 第 1 段 | 🔴 高 | "..." | 工整排比 | "..." |

### 详细分析

[对高风险问题的详细分析]

### 改写建议

[具体的改写方案，保持原意]
```

## 改写技巧

### 1. 打破工整句式
```
❌ 首先，...。其次，...。再次，...。最后，...。
✅ 第一，...。在此基础上，...。进一步地，...。综合来看，...。
```

### 2. 替换模板表达
```
❌ 值得注意的是，本文发现...
✅ 本文的发现表明... / 实证结果显示...
```

### 3. 增加具体内容
```
❌ 这具有重要意义。
✅ 这一发现为理解...提供了新的视角，对...政策的制定具有参考价值。
```

### 4. 使用复杂句式
```
❌ 本文研究了 X。本文发现了 Y。
✅ 本文在研究 X 的过程中，意外发现了 Y，这一结果与既有理论形成对话。
```

## 注意事项

- 检测结果仅供参考，不保证通过所有 AIGC 检测系统
- 改写时保持学术语言的规范性
- 不要过度改写导致语言不通顺
- 核心观点和专业术语不做改动
