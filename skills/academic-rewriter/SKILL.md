# /academic-rewriter - 学术语言润色与改写

## 用途

对学术论文内容进行语言润色和改写，提升学术性、降低 AIGC 痕迹、改善可读性。

## 使用方法

```
/academic-rewriter [文件路径或文本]
```

## 润色维度

### 1. 语言学术化

| 问题类型 | 原文 | 修改后 |
|----------|------|--------|
| 口语化 | 我们觉得 | 本文认为 |
| 非正式 | 这个发现 | 该发现 |
| 随意表达 | 大概是 | 可能/约为 |
| 主观表述 | 我相信 | 本文推测 |

### 2. 句式优化

| 问题 | 修改方向 |
|------|----------|
| 句子过短 | 合并为复合句 |
| 句子过长 | 拆分为多个句子 |
| 单调句式 | 增加变化（主动/被动、陈述/倒装） |
| 缺少连接 | 补充逻辑关联词 |

### 3. AIGC 痕迹消除

重点改写以下模式：

```
❌ "首先...其次...再次...最后"
✅ 调整顺序词：第一/第二/第三，或逻辑递进

❌ "值得注意的是"
✅ 直接陈述或换用"本文发现"

❌ "具有重要意义"
✅ 具体说明意义所在
```

### 4. 经济学专业表达

| 通用表达 | 学术表达 |
|----------|----------|
| 不一样 | 异质性 |
| 相互影响 | 交互作用/内生性 |
| 越来越 | 呈现...趋势 |
| 造成 | 引致/导致 |
| 检查 | 检验/验证 |

## 输出格式

### 模式一：对比输出

```markdown
## 润色报告 | [文件名]

### 原文
[原始段落]

### 润色后
[修改后段落]

### 修改说明

| 位置 | 修改类型 | 原文 | 修改后 | 理由 |
|------|----------|------|--------|------|
| 第 1 句 | 学术化 | "我们" | "本文" | 避免人称代词 |
```

### 模式二：直接修改

直接在文件中执行修改（需用户确认），并使用 LaTeX 注释标注修改处：

```latex
% [REWITER: 语言润色] 原句：...
修改后的句子
% [END REWRITER]
```

## 润色原则

### 必须遵守

1. **不改变原意**: 学术观点和论证逻辑保持不变
2. **不虚构内容**: 不添加原文没有的数据、引用或结论
3. **不破坏格式**: 保持 LaTeX 命令和引用格式完整
4. **说明理由**: 重要修改需简要说明原因

### 优先考虑

1. **简洁优先**: 能简则简，避免冗余
2. **清晰优先**: 复杂思想用清晰语言表达
3. **规范优先**: 符合经济学论文写作规范
4. **自然优先**: 避免机械化、模板化表达

## 润色级别

### 轻度润色
- 仅修正明显的口语化表达
- 保持原文结构和风格
- 适用于已较成熟的稿件

### 中度润色
- 优化句式和段落结构
- 替换非学术表达
- 适用于初稿完善

### 深度润色
- 全面重写，大幅提升学术性
- 调整论证逻辑和表达顺序
- 适用于需要大幅修改的稿件

## 常用技巧

### 1. 同义替换
```
研究→探讨/考察/分析
发现→揭示/表明/显示
证明→验证/证实/支持
```

### 2. 句式转换
```
主动→被动："本文发现 X"→"X 被发现"
肯定→否定："很少"→"不多见"
直接→间接："X 导致 Y"→"Y 可部分归因于 X"
```

### 3. 逻辑强化
```
添加："进一步地"、"与此一致"、"相反"
总结："可见"、"由此"、"据此"
因果："鉴于"、"出于"、"有赖于"
```

## 注意事项

- 专业术语不做同义替换
- 数学公式和推导保持原样
- 引用文献信息不做改动
- 图表标题和注释谨慎修改
- 修改后需通读检查流畅性
