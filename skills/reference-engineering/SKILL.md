# 学术参考文献工程 (reference-engineering)

## 触发场景
- 申报书/论文定稿时参考文献编号重排（正文引用编号与表对应）
- 文献真实性验证（中文/英文，评审可DOI反查）
- 期刊级别标注（CSSCI来源/扩展版/北核/非CSSCI）
- 评审指出"近两年文献缺失"需要补充（致命缺陷类反馈）

## 一、GB/T 7714顺序编码制重排（核心工程）

### 规则
- 正文引用编号 = 首次出现顺序；再次引用同一文献用同一编号
- 参考文献表编号连续无空号；表内每条必须被正文引用（背景文献不入表，正文用作者-年份转述）
- 新增文献插入正文后必须整体重排（不能局部补号）

### 工作流（一次性从源文件重建，勿增量修改）
1. 源综述的正文 + 参考文献表分开解析
2. 新增文献用占位编号（E1、E2…）插入正文对应脉络位置
3. 统一重排：扫描正文引用顺序 → 建立旧编号→新编号映射 → 替换正文 → 表按新编号排序输出
4. 验证三条件：正文唯一引用数 == 表条目数、表编号连续1-N、正文引用按序严格递增

### Python陷阱（详见 references/gb7714-sequencing-pitfalls.md）
- **int/str键不匹配**：表条目解析用int键、正文引用映射用str键 → 匹配恒False → 条目被当"未引用"丢弃 → 重排后表被覆盖丢失。统一用str键！
- **表覆盖丢失**：重排脚本若把"未引用"条目过滤后再写回，会覆盖旧表且无法恢复。必须从源文件（如V2综述）一次性重建完整表，绝不增量覆盖
- **锚点编号漂移**：升级综述时正文编号会变（如孙晓华[11]→[12]），插入锚点不能用含编号的文本，用纯文本片段或先查实际文本
- **中文引号SyntaxError**：Python字符串里中文引号（""）易触发语法错误，用 \u201c\u201d 转义拼接
- **裸条目无编号前缀**：追加新文献条目时漏写"[E12] "前缀 → 正则匹配不上 → 静默丢失。所有条目统一 "[编号] 内容" 格式
- **pandoc自动编号**：md的"1. xxx"转docx后变Word自动编号（python-docx读不出编号文本，属正常，Word打开可见）

## 二、文献真实性验证（双路径）

### 中文文献
- ❌ Crossref查中文DOI必404（中文DOI注册于chndoi.org/万方，不在Crossref注册）——404 ≠ 文献不存在
- ✅ doi.org全局解析：`https://doi.org/10.xxxx` 302重定向到chndoi.org或万方即有效（curl -I 或 urllib 跟随重定向）
- ✅ 期刊官网验证：税务研究官网、上海财经大学期刊社(qks.sufe.edu.cn)、中国人口·资源与环境(geores.com.cn) 等有完整元数据（卷期页码+DOI+作者），浏览器访问确认
- 中文CSSCI刊（税务研究/管理评论/宏观经济研究等）未稳定入Crossref，核实以PDF精读trail + 知网/万方为准

### 英文文献
- ✅ Crossref API按DOI反查：题名/期刊/年/卷期页码/作者全字段
- ⚠️ 检索候选必须按DOI反查完整元数据——检索列表里的作者名可能不准/占位符，必须替换为Crossref真实作者（零编造红线）
- ⚠️ 新文献（2025-2026）摘要常为空（Semantic Scholar/OpenAlex未收录）→ 用标题+期刊+领域知识做"摘要级解读"，标注⚠️，正文不引用未证实的具体数值

## 三、期刊级别核实（CSSCI官方目录）

- 南财图书馆页面含CSSCI 2025-2026目录xlsx：`http://lib.nufe.edu.cn/2025/0902/c463a11884/page.htm`（页面内找xlsx附件链接下载）
- xlsx结构：每个sheet = 一个学科，**4列**（序号|期刊|序号|期刊）——第2列=CSSCI来源，第4列=CSSCI扩展版（用 openpyxl 解析时取 row[1] 和 row[3]，不是 row[0]/row[2]）
- ⚠️ 2025-2026版重大变化（已实测）：科技管理研究/湖北社会科学/中国环境管理/环境经济研究/工业技术经济/北京理工大学学报(社科版) → **CSSCI扩展版（非来源刊）**；国际税收/税务与经济同理
- 认定规则：按**发表当年**的CSSCI目录认定（发表时是CSSCI来源的仍可引，标注"发表时CSSCI/现扩展版"）

## 四、近两年文献补充（评审硬指标）

- 触发：综述近两年（2025-2026）文献占比过低。经验值：<15%即警示，本项目6%→26%才被认可
- **策略1 存量盘活（优先）**：先扫已有文献清单/解读文件中近两年文献——少帅明确"中文文献给了那么多（CSSCI）应该有用得上的"，已解读未入综述的优先，零新增解读成本
- **策略2 期刊定向检索**：Crossref `query.bibliographic` + `from-pub-date:2025-01-01`；⚠️ 返回的container-title可能为空，按期刊名硬过滤会误杀全部 → 改用标题关键词强过滤（emission/carbon/trading/permit/tax/pollution/agent-based等）
- **策略3 官网验证**：中文新刊用 web_search/浏览器访问期刊官网确认卷期页码（Crossref/OpenAlex查不到中文期刊）
- **不堆砌证明**：新增文献做"文献 | 课题机制对应 | 引用位置 | 相关性"对照表，每篇承担明确论证功能
- 英文近两年优先检索：JEEM / Energy Economics / Energy Policy / EJOR / EIA Review / Energy Efficiency 等SSCI/SCI，2025-2026

## 五、出口验证（交付前必做）

- 正文唯一引用数 == 表条目数
- 表编号连续1-N 且 正文引用按序严格递增
- 2025/2026占比统计：⚠️ 用 ", 2025" 或 "2025," 模式提取，中文标题里的"2012—2021年"会误匹配年份（先取期刊年份位置）
- 中英文DOI抽查（中文doi.org解析/英文Crossref）
- 交付：md+pandoc转docx（公式转OMML），知识库+output双落盘，飞书发送
