# 学术论文战略规划师 (Academic Paper Strategist)

## 概述

本技能提供从研究想法到投稿级大纲的系统化规划框架，包含AI驱动的文献检索、研究空白识别、原创性评估和审稿人视角的大纲优化。

**输出**: 详细、可投稿的论文大纲 + 完整的支撑文档（选刊指南、文献综述、空白分析、审稿评估）

**配套技能**: 使用 **academic-paper-composer** 执行大纲并撰写全文

---

## 何时使用

**规划阶段**:
- 从初步想法设计研究论文
- 识别合适的发表平台（期刊/会议/预印本）
- 了解目标平台的写作标准

**研究阶段**:
- 系统性文献检索
- 有证据支撑的研究空白识别
- 评估研究想法的原创性
- 预测潜在影响力

**设计阶段**:
- 论文章节和论证结构设计
- 审稿人视角的大纲优化
- 准备投稿策略

**触发词**:
- "帮我规划一篇关于[主题]的论文"
- "帮我设计一篇关于[主题]的论文"
- "找出[领域]的研究空白"
- "这个想法有原创性吗？"
- "我应该投哪个期刊/会议？"

---

## 工作流程

```
阶段一：目标平台分析（选刊 + 写作标准学习）
    ↓
阶段二：理论框架（AI驱动的文献检索与空白识别）
    ↓
阶段三：大纲优化（审稿人视角的质量控制设计）
    ↓
输出：详细大纲 + 完整支撑文档
```

**质量门控**: 3个验证检查点确保每个阶段达标后才进入下一阶段

---

## 阶段一：目标平台分析

### 目标
通过系统化的样本文献分析，识别最优投稿平台并理解其写作标准。

### 需要用户提供
- **核心研究想法或主题**（简要描述）
- **目标平台**（可选——不明确时我会推荐）
- **学科领域**

### 工作流程

#### 步骤1.1：选刊/选会（如需要）

如果目标平台不明确：

1. **列出候选平台**:
   - **SCI期刊**: 根据研究内容匹配JCR分区
   - **IEEE会议**: 适合工程/计算机领域
   - **Nature系列**: 高影响力跨学科研究
   - **arXiv**: 预印本，快速发布
   - **领域顶会**: IJCAI、NeurIPS、TRO等

2. **评估每个平台**:
   - 学科匹配度
   - 方法论契合（理论/实证/计算）
   - 影响因子与分区
   - 审稿周期与接收率

3. **提供推荐**（含理由）

4. **决策点1**: 用户确认平台或提出替代方案

#### 步骤1.2：样本文献检索（AI驱动，质量可控）

搜索 **8-10篇** 代表性论文：

**搜索策略**:
- **时间维度**: 近6个月(3篇) + 1-2年(3篇) + 经典高引(2篇)
- **相关性维度**: 关键词组合，相关性评分≥7/10
- **多样性维度**: ≥5位不同作者，不同研究视角

**质量门控1**（必须通过）:
- ✓ 样本文献 ≥8篇
- ✓ 时间分布均衡
- ✓ 平均相关性 ≥8/10
- ✓ 不同作者 ≥5位

#### 步骤1.3：写作标准提取

从样本文献中提取：
- **结构模式**: 摘要结构、章节组织、篇幅比例
- **风格模式**: 主动/被动语态、论证结构、引用密度
- **格式规范**: 典型字数、参考文献数量、标题规范

**输出**: `[平台]_写作标准指南.md`

## 阶段二：理论框架

### 目标
AI驱动的系统性文献检索、研究空白识别和原创性评估。

### 需要用户提供
- **核心研究问题/论点**
- **背景信息**（为什么感兴趣）
- **已知文献**（可选）

### 工作流程

#### 步骤2.1：文献检索（AI驱动，全自动）

**多轮搜索策略**:

**第1轮：直接搜索（核心文献）**
1. 提取核心概念（3-5个）
2. 生成关键词组合（10-15组）
3. 搜索每组关键词
4. 收集30-50篇候选文献
5. 质量筛选：保留相关性≥7/10的前20篇

**第2轮：扩展搜索（相邻领域）**
1. 从第1轮文献中提取新关键词
2. 搜索相邻学科
3. 收集10-20篇桥接文献

**第3轮：经典文献（奠基性工作）**
1. 识别高被引文献（>100次引用）
2. 追踪第1-2轮文献的引用链
3. 收集5-10篇奠基性文献

**文献库总量**: 35-50篇

#### 步骤2.2：研究空白识别（AI分析）

使用收集的文献自动识别 **3-5个研究空白**：

**识别方法**:
1. **概念映射**: 在概念×方法矩阵上找空白区域
2. **问题-方案分析**: 文献解决了什么问题？留下了什么未解？
3. **时间分析**: 什么被研究过但放弃了？什么新出现但未被探索？

**空白类型**:
- **完全空白**: 无现有研究
- **部分空白**: 仅有初步工作，需深入
- **争议空白**: 竞争理论未解决

**每个空白需记录**:
- 清晰定义（50-100字）
- 证据（3-5篇引用证明空白存在）
- 重要性评估（高/中/低）
- 可行性评估（能否填补？）

**质量门控2**（必须通过）:
- ✓ 文献库 ≥20篇
- ✓ 识别空白 ≥3个
- ✓ 每个空白 ≥3条证据
- ✓ 至少1个高重要性空白

#### 步骤2.3：原创性评估（AI分析）

**步骤1：相似性分析**
- 与最相似的15篇论文对比
- 创建相似性矩阵（主题/方法/结论重叠）
- 计算总体相似度百分比

**解读**:
- >80%: 高相似，需重新定位
- 50-80%: 中等，强调差异
- <50%: 原创性好，继续

**步骤2：创新分类**（需满足≥2项）:
1. **方法论创新**: 对已知问题的新方法
2. **理论创新**: 新框架或模型
3. **应用创新**: 现有理论应用于新领域
4. **整合创新**: 综合多个独立文献

**步骤3：影响力预测（1-10分）**
- 空白重要性（5分）
- 可推广性（3分）
- 解释力（2分）

**输出**: `原创性评估报告.md`

#### 步骤2.4：核心概念讨论（交互式）

**决策点2**: 基于文献分析：
1. 提出3-5个应强调的核心概念
2. 解释理由（基于空白分析+文献频率）
3. 请用户反馈：同意？调整？补充？

---

## 阶段三：大纲优化

### 目标
设计结构化的、审稿人视角优化的论文大纲。

### 工作流程

#### 步骤3.1：初始结构设计

1. **设计章节结构**: 摘要→引言→主体(3-5章)→结论
2. **分配篇幅**: 引言15-20%，主体60-70%，结论10-15%
3. **确定论证流**: 概念引入位置、反驳处理位置

#### 步骤3.2：审稿人视角自评

**7维度评估**（每项5分，总分35分）:

1. **论证清晰度** (1-5): 论点明确？支撑论证可识别？
2. **论证完整性** (1-5): 逻辑跳跃？前提充分论证？
3. **文献支撑** (1-5): 引用量充足？关键文献覆盖？
4. **方法论清晰度** (1-5): 方法明确且合理？
5. **原创性表达** (1-5): 贡献清晰？与现有工作区分？
6. **组织结构** (1-5): 逻辑流畅？比例均衡？
7. **平台契合度** (1-5): 风格匹配？格式正确？

**通过阈值**: ≥28/35 (80%)

#### 步骤3.3：优化建议（数据驱动）

对每个得分<4/5的维度：
- **问题描述**: 具体什么问题？
- **严重程度**: 高/中/低
- **具体方案**: 可操作的修复方法
- **预期提升**: 能提高多少分？

**决策点3**: 用户决定：全部接受 / 选择性采纳 / 修改建议

#### 步骤3.4：最终大纲生成

```markdown
# [论文标题]

## 摘要 (250词)
- [要覆盖的要点]

## 1. 引言 (1,500词)
### 1.1 问题提出 (400词)
- [具体内容指导]
### 1.2 文献综述 (600词)
- [要讨论的理论]
### 1.3 本文贡献 (500词)
- [要提出的具体主张]

## 2. [主体章节] (1,200词)
### 2.1 [小节] (400词)
- [论证结构]
- [关键引用]
...

## 参考文献
- [预期40-60篇]
```

**质量门控3**（必须通过）:
- ✓ 审稿人评分 ≥28/35
- ✓ 所有高严重度问题已解决
- ✓ 篇幅分配总和=目标总字数

## 完整输出文档

1. **`[平台]_写作标准指南.md`** — 平台风格、结构模板、引用规范
2. **`样本文献评估报告.md`** — 8-10篇分析文献、质量指标
3. **`文献综述报告.md`** — 35-50篇核心文献、按主题组织
4. **`研究空白分析.md`** — 3-5个空白、证据包、重要性评估
5. **`原创性评估报告.md`** — 相似性分析、创新分类、影响力预测
6. **`审稿人评估报告.md`** — 7维度评分、问题识别、优化建议
7. **`优化详细大纲.md`** ⭐ **主要交付物** — 完整结构、篇幅分配、内容指导

## 常见问题

### 问题1：文献检索不够全面
**解决**: 扩展关键词组合，增加搜索轮次，检查相邻领域覆盖

### 问题2：研究空白不明显
**解决**: 换角度分析（概念映射→问题-方案→时间分析），或调整研究方向

### 问题3：大纲审稿人评分低于阈值
**解决**: 针对弱维度逐一改进，重新评估直到通过

## 最佳实践

1. **提供清晰的研究想法**: 越具体，文献检索越精准
2. **信任AI驱动的搜索**: 文献检索、空白识别、原创性评估全自动完成
3. **在决策点积极参与**: 3个决策点塑造最终大纲
4. **使用质量验证**: 质量门控确保不达标不放行
5. **需要时迭代**: 阶段不达标就重新来过
