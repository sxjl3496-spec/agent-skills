# CSSCI 期刊级别核实方法（2026-08 文献战役实测）

## 目录获取

CSSCI 2025-2026 官方目录（南京大学中国社会科学研究评价中心发布）的 xlsx 可从高校图书馆页面下载：
- 南京财经大学图书馆：`lib.nufe.edu.cn` 搜索 "CSSCI2025-2026.xlsx"（页面内有真实 xlsx 附件链接，需从 HTML 中提取 `href="...xlsx"`）
- 绍兴文理学院：`lib.usx.edu.cn` 页面附件
- 扩展版目录也有独立 PDF（如 hualixy.edu.cn）

## openpyxl 解析（⚠️ 关键坑：5列表结构）

每个 sheet 的实际结构是 **5 列**（不是2列）：
```
CSSCI（N种） | (空) | (空) | CSSCI扩展版（M种） | (空)
序号 | 期刊 | (空) | 序号 | 期刊
1   | 期刊A |      | 1   | 期刊B
```

- **CSSCI 来源期刊在 row[1]，扩展版期刊在 row[4]**
- 只看 row[0]/row[1] 会把第一列序号当期刊过滤掉、把来源期刊误判为扩展版（第一轮解析实测踩坑：CSSCI=1 扩展版=661 的荒谬结果）
- 正确代码：
```python
if len(row) > 1 and row[1]: cssci.add(str(row[1]).strip())
if len(row) > 4 and row[4]: ext.add(str(row[4]).strip())
```

## 级别认定规则

1. **按发表当年的 CSSCI 目录认定**，不只看最新版：科技管理研究 2016/2017 年发表时是 CSSCI 来源（2014-2024 目录），2025-2026 版已转扩展版 → 标注"CSSCI(发表时)/现扩展版"
2. **CSSCI 扩展版 ≠ CSSCI 来源期刊**：扩展版在引用原则上按"准核心"处理（可作背景或酌情引用，明确标注）
3. 少帅（用户）手动标注优先于目录判断（如"非CSSCI★少帅标注"）

## 2025-2026 版已转 CSSCI 扩展版的常见期刊（实测核实）

科技管理研究、湖北社会科学、中国环境管理、环境经济研究、工业技术经济、北京理工大学学报(社会科学版)、税务与经济、国际税收、环境保护

## 与北大核心（北核）的区别

CSSCI 目录不含北核期刊（价格理论与实践、水利经济、系统仿真学报等为北核但非 CSSCI）——引用时分别标注"北核(非CSSCI)"。CSSCI 扩展版、北核、非核心是三个不同档次。
