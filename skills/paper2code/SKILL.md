# Paper2Code（论文转代码复现）

## 适用场景

把一篇学术论文（ABM/计量/仿真）转化为可运行、可复现的代码与实验。

## 5 阶段流水线

1. **论文获取**（paper_acquisition）：定位论文、补充材料、数据集；记录版本与获取路径
2. **贡献识别**（contribution_identification）：提炼核心主张（模型结构/数据/结果）——为每条主张建立"代码对应物"映射
3. **歧义审计**（ambiguity_audit）：**诚实标注所有歧义**——参数未给/公式符号不清/算法步骤省略，逐条列出，不默认填补
4. **代码生成**（code_generation）：按歧义清单决策——可查证的补全（标注来源）、不可查证的用默认值（标注"假设"）或询问
5. **讲解 Notebook**（walkthrough_notebook）：逐步复现，每一步链接论文章节

## 防幻觉护栏（铁律）

- ❌ **绝不发明**论文中未说明的实现细节（参数值、算法变体、数据结构）
- 必须使用假设值时：在代码注释与 README 中显式标注 `[ASSUMPTION]`，并在交付说明中列出全部假设清单
- 论文写得很差/信息缺失时：优先联系原文或找替代实现，而非猜测

## 实战案例（本团队）

碳市场 ABM 论文复现：原型 300 智能体×CDA 订单簿，行为参数（λ=2.25、σ_c=0.6）均有来源标注；Morris 敏感性 6 参数全部参数化后重跑（首版 4/6 参数未生效已作废重建）——防幻觉护栏 + 证据门控双保险。

## 交付物

- 可运行代码（含种子设定，可复现）
- 假设清单（全部 `[ASSUMPTION]` 汇总）
- 复现实验记录（结果对比论文数字）
