# Prompt 模板库 (prompt-templates)

## 何时使用

- 执行常见任务类型时，套用模板减少规划开销
- 需要保证同类任务输出格式一致
- 新会话中快速启动标准工作流

## 模板列表

### 1. 技术调研模板

```
任务：调研 [主题]

维度：
1. 定义与核心理念
2. 技术架构（关键概念/模式/组件）
3. 代表项目（GitHub仓库名+star数+简介）
4. 应用场景
5. 优缺点对比

搜索来源：GitHub API + Google（走Clash代理7897）
输出语言：中文
输出格式：Markdown，含表格和代码块
```

### 2. 代码审查模板

```
任务：审查以下代码

检查维度：
1. 正确性：逻辑是否正确，有无bug
2. 健壮性：错误处理是否完善，边界条件
3. 可读性：命名、注释、结构
4. 性能：是否有明显的性能问题
5. 安全性：是否有安全漏洞

代码：
[粘贴代码]

输出格式：
- 每个维度评分（1-5）
- 发现的问题列表（按严重度排序）
- 改进建议
```

### 3. 文档写作模板

```
任务：撰写 [文档类型]

结构：
1. 概述（一句话+一段话）
2. 背景/动机
3. 核心内容（分小节）
4. 对比分析（表格）
5. 结论/建议

要求：
- 中文
- 每小节不超过300字
- 关键信息用表格
- 源链接放在末尾
```

### 4. 方案评估模板

```
任务：评估方案 [方案名称]

评估维度：
1. 可行性（技术/资源/时间）
2. 风险（列出风险点和应对）
3. 成本（token/时间/金钱）
4. 收益（效率/质量/体验提升）
5. 替代方案对比

输出格式：
| 维度 | 方案A | 方案B | 推荐 |
|------|-------|-------|------|

结论：推荐方案X，理由：...
```

### 5. 知识库归档模板

```
任务：将以下内容归档到 Obsidian Vault

路径：<Obsidian库>\\[分类]\

格式要求：
- YAML frontmatter（tags, created, updated, sources）
- 标题层级：# ## ### （不超过3级）
- 双链：[[相关笔记名]]
- 表格：用 Markdown 表格，不用 HTML
- 代码：用 ```language 代码块
```

### 6. 问题诊断模板

```
任务：诊断 [问题描述]

流程：
1. 确认症状：具体表现、触发条件
2. 排查假设：列出可能原因
3. 验证步骤：逐一验证假设
4. 根因定位
5. 修复方案+验证

输出格式：
- 症状：...
- 根因：...
- 修复：...
- 验证：...
```

## 使用方式

直接在任务描述中引用模板编号，或按模板结构组织任务。

## 扩展

当某个任务类型被重复执行3次以上，将其 prompt 固化为新模板添加到本文件。
