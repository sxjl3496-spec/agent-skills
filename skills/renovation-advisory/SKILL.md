# 装修咨询：谈判、合同与报价

## 核心原则

1. **主动权在你手里** — 你是付钱的人，装修公司应该争取你，不是你去求他们。
2. **不给钱之前，一切都是可谈的** — 一旦交了全款，你就从甲方变成了乙方。
3. **货比三家是硬道理** — 不要只听一家说，跑三家报价自然有答案。
4. **合同看字不看话** - 口头承诺不算数，写在纸上的才算。
5. **数据缺失≠能力存疑** - 大品牌没有验证记录不等于能力差，小公司有验证记录不等于更优。比较公司时，不能因为A有某项已验证数据而B没有，就偏向A。要看整体实力画像。大品牌的品牌荣誉、资质等级、工艺体系本身就是能力证据，只是维度不同。

---

## 第一阶段：谈判策略

### 定金策略

装修公司常见的压力话术：「必须先付全款才能开始设计」。

反击策略：「先付少量定金（1000-5000）→ 出初步方案 → 满意抵扣进总价」。

- 这是**行业通行做法**，不是非分要求
- 如果对方拒绝，说明他怕你看了方案跑路——那方案本身可能不行
- 话术：「我是诚心要在你这做的，定金放你这我跑了你也赚了，你不亏」

### 报价虚高的识别

三线城市（如湘潭）家装设计费市场参考（2026.07 五家实调）：

| 档次 | 价格 | 包含 | 实例 |
|------|------|------|------|
| 正常 | 3000-6000 | 平面图 + 效果图 + 施工图 | 创艺/金煌/千思均为5000 |
| 偏贵 | 6000-8000 | 含效果图 + 施工跟踪 | — |
| 虚高 | 8000+ | 必须有案例+流程清单+现场专业度支撑 | 山木1.2万无效果图→淘汰 |

报价明显高于市场价时，要求对方用实力证明：「往期案例、设计流程清单、现场专业度」三项至少满足两项。

### 「同事/熟人背书」话术

常见套路：「你同事也在我这做了，还愿意推荐」。

破法：**要联系方式，你自己去问。**
- 「那你推他微信给我，自己同事问起来方便」
- 推了 → 拿到真实反馈
- 不推 → 话不可信，不做决策依据

这是用「权威背书」代替「实力证明」，本质是制造 FOMO。

### 交叉验证策略（多公司并行）

最有效的甄别手段：拿 A 公司的方案去问 B 公司「这个方向你能优化吗」。

- 如果两家独立得出同样的布局结论 → 说明方向正确（如金煌和青尚都得出开放厨房+主卧套房）
- 如果 B 公司说「改不了」→ 淘汰（要么能力不够，要么态度不行）
- 优势：不等一家家排队出图，并行推进节省时间窗口

## 第二阶段：合同审查

### 定金 vs 订金（法律差异）

| | 定金 | 订金 |
|---|---|---|
| 法律性质 | 担保，违约有罚则 | 预付款 |
| 可退性 | 违约方不退/双倍退 | 可退 |
| 合同用字 | 严谨的担保合同 | 普通委托合同 |

**家装场景优先用「订金」而非「定金」。** 要求合同明确写「无理由退还」。

### 定金的双刃剑（用户需理解的核心法律点）

定金罚则是双向的：甲方违约不退，乙方违约双倍退。用户有时认为"定金也约束装修公司"，但实际**不对称**：

| 场景 | 装修公司说法 | 用户说法 | 谁算违约？ |
|------|------------|---------|-----------|
| 公司根本不出图 | "我确实没履约" | 要求双倍退 | ✅ 公司违约 |
| 公司出了图但用户认为敷衍 | "我出图了，是你不满意" | "这叫敷衍不叫履约" | ⚠️ 灰色地带 |
| 公司出了图用户不签施工合同 | "我履约了，是你违约" | "不满意有权不签" | ⚠️ 可能判用户违约 |

**关键**：审美是主观的，公司只要"出了图"就很难被认定为"不履约"。而用户"不满意"在法律上很难证明"图烂到构成违约"。

**最优方案**：不一定非改"订金"，可保留"定金"+加对等条款：
- 条款A："乙方应于X日前交付不少于N张效果图，经甲方书面确认满意后方可视为设计履约完成。逾期或经3轮修改仍未满意，甲方有权终止合同，乙方双倍返还定金。"
- 条款B："效果图经3轮修改仍未满意，甲方有权终止合作。乙方退还全额定金，设计费按实际工作量结算，不按原价收取。"
- 条款C："乙方逾期交付，每逾期1日按定金1%支付违约金。逾期超15日，甲方可解除合同并要求双倍返还。"

### 合同必查清单

1. **退款条款**：是否写了「可退」？**退款时限**写了没有？（必须加：3 个工作日内退还）
2. **交付物范围**：平面图？效果图？几张？什么空间？
3. **时间期限**：什么时候交图？
4. **抵扣条款**：订金是否抵扣总价？
5. **设计费优惠条件**：优惠价的前提是什么？（常见陷阱："不在本公司施工按原价收取"，原价可能是优惠价的2-3倍）
6. **效果图赠送数量**：合同通常只送1张，额外800元/张。要求至少3张（客/餐/主卧）
7. **施工图格式**：合同写"纸质版"还是"电子版DWG"？必须要求同时给电子版
8. **0增项承诺**：六大服务承诺/宣传资料里写了"0增项闭口合同"，但定金合同里有没有写？要求写进去
9. **材料品牌锁定**：报价单是否写明品牌/型号/环保等级？不写品牌等于空头支票

### 常见漏洞

- 交付物过于模糊（如只写「设计方案」不写是否含效果图）
- 退款不退时间（只承诺退，不承诺多久退——可能拖几周）
- 口头的承诺没写进合同
- **「包改到满意」是空头支票**——设计师态度差、敷衍了事时，这条款无法强制执行。如果对方拒绝修改且不肯退费，对策：
  1. 微信发文字要求退费（留证据），明确「合同写包改到满意，你现在拒绝履约，退钱」
  2. 不回复就去门店，挑有客户在谈的时候去，声音不用大但旁边的人会听到
  3. 扯「量房费/成本费」时要求指出合同哪一条写了，行业惯例量房免费
  4. 最后手段：12315 投诉（装修纠纷），有合同+付款记录即占理
  5. **核心判断：设计阶段就敷衍的人，施工图阶段会更差。退钱走人比换人继续改更对。**

## 第三阶段：设计师能力甄别

三个必问问题：

1. **看案例**：「往期实景案例给我看看--实景照片，不是效果图。」-> 真正的定制设计师一定有落地案例
2. **看流程**：「你的设计服务包含什么？量几次房？出哪些图？改几次？去几次工地？」-> 列清单才能比价
3. **试专业度**：问一个户型具体问题，如「我家客厅采光一般，你打算怎么处理？」-> 有水平的设计师能当场说出有见地的想法，套模板的会含糊其辞

## 第三阶段补充：设计-施工分离谈判策略

当用户对某公司的设计能力有信心但对施工能力未验证时，可采用"先做设计，满意后再谈施工"的策略。

### 三套合同方案（按谈判优先级）

**方案一：订金版·设计服务合同**（首选）
- 只做设计，不绑定施工
- "订金"形式，可退
- 交付物：效果图（明确张数+空间）+ 全套CAD施工图（含电子版）+ 平面方案
- 关键条款："不在本公司施工也只收约定设计费，不按原价收" + "设计成果归甲方"
- 退出条款："效果图经3轮修改仍不满意，乙方全额退还订金"
- 后续：满意->设计费抵扣工程款->签施工合同；不满意->退订金走人

**方案二：订金版·施工定金合同**（公司坚持打包时）
- "订金"形式（非"定金"），可退
- 设计+施工打包，但设计满意后才签正式施工合同
- 必须改3条：定金->订金 + 不在金煌施工不按原价收 + 效果图不满意退订金

**方案三：定金版·施工定金合同**（公司坚持用"定金"时）
- 保留"定金"双向约束
- 必须加对等条款（见上方"定金的双刃剑"三条款）
- 明确"履约标准"：不是出了图就叫履约，要甲方书面确认满意

### 谈判核心话术

> "我诚心在这做，但设计满意了才谈施工。设计费我现在就付，图纸归我，不满意能退，满意了设计费抵工程款。你们对自己设计有信心，这条件对谁都不亏。"

### 防敷衍核心机制

1. **每个节点签字才付款** -- 效果图不签字不付设计费尾款，施工图不签字不签施工合同
2. **效果图数量写进合同** -- 按空间明确张数（如套房4张/小孩房1张/老人房1张/餐客厅厨房4张）
3. **出图期限写进合同** -- 效果图7天，施工图确认后10天，超期可退
4. **改图机制** -- 至少3轮，最好不限次数
5. **设计师级别写进合同** -- 主任/高级/首席，可更换同级别

## 第四阶段：风险分析框架

装修合同谈判的两种风险：

| 风险类型 | 说明 |
|----------|------|
| **法律风险** | 钱拿不回来（订金合同 + 无理由退还条款 → 几乎为零） |
| **时间风险** | 钱退了但时间白花了（真正需要注意的风险） |

评估逻辑：如果「花 X 元押金 + Y 周时间，换一个验证这家公司水平的机会」值得 -> 签。如果不值得 -> 换。

### ⚠️ 评估陷阱：数据缺失 ≠ 能力存疑

比较装修公司时，容易犯一个错误：A公司有某项验证数据（如还原度90%），B公司该项数据缺失（标注"未知"），就倾向推荐A。**这是错的。**

- "数据缺失"只说明"还没验证"，不等于"能力不行"
- 大品牌（25年/鲁班奖/一级资质）大概率能力过硬，只是还没拿到验证数据
- 正确做法：对数据缺失的公司，**明天去验证**（看实景案例），而不是直接排除
- 如果大品牌能拿出实景案例 -> 在几乎所有维度上碾压小公司
- **不要把"数据缺失"当成"能力存疑"的依据**

## 第五阶段：材料品牌资料解读

装修公司发的图片资料≠效果图。收到图片后，**第一步是分类**，第二步才按类型评估。

### 图片分类（收到图片先做这一步）

| 类型 | 识别特征 | 评估方法 |
|------|---------|---------|
| 效果图 | 3D渲染的室内空间，有家具/灯光/材质表现 | 用50个坑清单逐条排查 |
| 施工范围表 | 表格形式，按空间列出施工项目，黄色/白色背景 | 检查覆盖面，但重点问缺什么（品牌/价格/型号） |
| 材料品牌宣传 | 产品截面图/优势列表/品牌介绍/工厂照片 | 见下方"材料评估框架" |
| 检测报告 | 有报告编号/检测机构名称/合格判定 | 验证机构资质+核对关键指标 |
| 品牌荣誉 | 奖杯/奖状/竞赛照片/项目照片 | 区分工程端vs家装端荣誉 |
| 工地监控系统 | 摄像头/APP界面/监控截图 | 评估远程管理能力（对外地业主特别重要） |

### 材料评估框架

当装修公司发来材料品牌宣传资料时：

1. **识别材料品牌与装修公司的关系** — 是自有品牌？战略合作？还是渠道商？
2. **检查环保等级** — ENF级（最高）> E0级 > E1级。ENF级有国标支撑，可信度高。
3. **验证检测报告** — 看出具机构（国家级>省级>第三方）、报告编号、检测日期。注意：实验室数据≠实际效果。
4. **分离营销话术与实质** — 以下话术是智商税信号，不作为决策依据：
   - "太赫兹波""远红外射线""养生保健"（硅藻土产品常见）
   - "纳米科技""量子"（无具体检测数据支撑时）
   - "净化率97%+"（实验室条件，实际家居环境打折）
5. **确认价格** — 材料宣传资料里通常没有价格，必须单独要报价
6. **确认应用范围** — 板材用在哪些地方（衣柜柜体？门板？墙板？全屋？）

### 品牌荣誉的辨别

| 荣誉类型 | 含义 | 注意事项 |
|----------|------|---------|
| 鲁班奖 | 中国建筑工程最高奖 | 通常是工程端荣誉，不代表家装施工质量 |
| 精装地产项目 | 万科/龙湖等大房企精装供应商 | 说明有规模能力，但大型精装是流水线作业 |
| 技能竞赛金奖 | 省级/市级装修工人技能比赛 | ✅ 实打实反映工人技术水平 |
| 品牌年限 | 公司成立年限 | >5年度过倒闭高危期，>10年较稳定 |

**核心原则：品牌荣誉是加分项，不能替代实景案例验证。大公司做家装，最大风险是流水线+外包。**

## 第六阶段：效果图落地能力评估

当用户拿到装修公司效果图后，从4个维度评估落地能力：

| 维度 | 含义 | 怎么验证 |
|------|------|---------|
| **① 材料可购性** | 效果图里的材质/颜色/款式，本地买不买得到、多少钱 | 直接问："这张图里墙面是什么材料？什么品牌？单价多少？" |
| **② 工艺可行性** | 造型复杂度（悬空吊顶、弧形墙、无主灯等）施工队做不做得出来 | 看实景案例有没有同款造型落地 |
| **③ 预算匹配度** | 效果图档次对应总报价是否在预算内 | 要报价区间："按这个效果图装下来全包多少？" |
| **④ 还原度** | 效果图→实景的还原比例 | **最关键**：要往期同风格实景照片+效果图对比 |

**关键判断**：效果图分数高 ≠ 落地能力强。PPT讲得好是销售能力，不是施工能力。品牌荣誉是工程端证据，不等于家装端施工质量。

### 设计-施工分离分析

用户可能问"能不能拿A公司的设计图找B公司施工"。结论：**理论上可行，实操有3个坑**：

1. **图纸不完整**：装修公司给客户看的是效果图，施工靠全套CAD施工图（平面/水电/天花/立面/节点大样）。只有效果图，施工方只能"凭感觉"做，还原度必然打折。且合同可能约定"图纸归公司所有，未签约不得带走"。
2. **互相甩锅**：设计方说"施工方手艺不行"，施工方说"设计不合理"，无人对最终效果负责。一体化公司（设计+施工）出问题找一家。
3. **材料对不上**：A公司的效果图基于特定品牌材料设计，B公司可能没有该渠道，替代材料颜色/质感/收口不同，效果打折。

**更好的策略——偷方向不偷图**：拿A公司的效果图方向（布局/配色/造型元素），让B公司按这个方向重新出图+施工。不偷图版权，取长补短（A的审美+B的落地能力），B公司设计施工一体有人负责。

**话术**（对B公司说）：
> "我去A公司看了，他们出了效果图，布局方向跟你们一致，效果确实不错。但我想在你们这里做，因为你们有实景案例，还原度高。你们能不能按这个方向重新出一版效果图？"

### 定金合同中的设计费陷阱

实际案例（金煌2026.07）：定金合同写"设计费原价12,800元，优惠价5,000元（前提：在本公司施工）。若最终不在公司施工，按原价收取。"

这意味着：拿图走人的代价不是5,000元，而是12,800元。且合同只赠送1张效果图，额外800元/张。

**谈判要点**：
1. "定金"改"订金" + 写明"3个工作日无理由退还"
2. 效果图至少送3张（客/餐/主卧）
3. CAD施工图要电子版（DWG），不只纸质版
4. "不在本公司施工按原价收"这条要谈：效果图不满意能否退？退多少？
5. 0增项闭口合同写入定金合同（不只写在宣传资料里）
6. 报价单写明品牌/型号/环保等级

## 陷阱速查

- [ ] 合同写的是「订金」还是「定金」？（如用「定金」，是否加了对等条款？）
- [ ] 退款时限写了吗？（建议 3 个工作日内）
- [ ] 交付物含效果图吗？几张？什么空间？（按空间写明张数）
- [ ] 设计费是否虚高（三线城市超 6000 要有充分理由）？
- [ ] 合同是否有「不在本公司施工按原价收设计费」条款？（必须谈掉或改为按约定价收）
- [ ] 口头承诺写进合同了吗？
- [ ] 「包改到满意」是否在合同里？如设计师敷衍，退费策略备好了吗？
- [ ] 是否要求对方出示《建筑业企业资质证书》原件？
- [ ] 是否参观了正在施工的工地？
- [ ] 是否索要了已完工客户的联系方式？
- [ ] **报价是「闭口价」还是「起步价」？**（用这句话验证："这个价格写死在合同里，0增项，后期不另外加钱，对吧？"）
- [ ] **定制柜体（衣柜/橱柜/餐边柜）在不在报价里？**（这是最大不确定项，可能3-5万）
- [ ] **水电改造/拆墙砌墙在不在报价里？**（有些公司按实另算）
- [ ] **宣传页上的承诺（0增项/假一赔三/CMA检测）是否写进合同正文？**
- [ ] **施工图是否含电子版？**（远程办公必需）
- [ ] **出图期限写了吗？**（效果图7天/施工图10天，超期可退）
- [ ] **设计师级别写进合同了吗？**（主任/高级/首席）
- [ ] 设计费优惠条件：不在本公司施工按原价收？原价多少？
- [ ] 效果图赠送几张？额外多少钱一张？
- [ ] 施工图给电子版DWG还是只给纸质版？
- [ ] 0增项闭口合同写进定金合同了吗？还是只写在宣传资料里？
- [ ] 报价单写明了品牌/型号/环保等级吗？
- [ ] 收到的资料包里有效果图吗？还是只有品牌/工艺/材料宣传？
- [ ] 品牌荣誉是工程端还是家装端？鲁班奖≠家装施工质量

## 第七阶段：保障服务文件分析与合同生成

### 保障服务文件分析框架

装修公司常出示「六大保障」「服务承诺」等展架/海报（带盾牌图标、总经理签字栏）。分析时重点看三点：

1. **是否绑定具体合同** -- 检查有无合同编号、日期、交叉引用。无则视为独立品牌承诺模板，对定金合同无直接法律影响。
2. **签字栏是否已填写** -- 全空 = 未签署的模板，任何人都能签同一张。已签 = 双方承诺文件，有约束力。
3. **条款是否有违约责任** -- 区分「口号」与「承诺」：
   - 有惩罚性条款（如"假一赔三""双倍处罚"）= 有法律效力
   - 只写"确保满意""保驾护航" = 营销话术，无强制力
   - 写"负责整改"但不写"赔偿" = 整改是义务但无额外赔偿

### 保障文件的谈判价值

保障文件虽不直接改变定金/订金性质，但可做谈判筹码：

> "你们六大保障写得好，尤其'全程0增项'和'设计满意'。那我要求把定金改订金，你们有六大保障还怕客户不满意走了不成？"

### 双版本合同生成工作流（谈判前准备）

为谈判准备两份 .docx 合同：一份「定金版」（对方可能提出的标准版），一份「订金版」（用户争取的版本）。核心差异用对比表呈现，让用户一目了然谈判焦点。

**技术实现**：用 `python-docx` 生成格式化中文合同文档（黑体标题/宋体正文/表格信息栏/签字栏），通过飞书发送给用户。

**关键差异点（定金版 → 订金版的5个改动）**：

| 条款 | 定金版（对方版本） | 订金版（用户版本） |
|------|--------|--------|
| 设计费总额 | ¥5,000（可能被追到原价12,800） | ¥5,000为最终价，不得追加 |
| 款项性质 | 定金（适用定金罚则） | 订金=预付款，不适用定金罚则 |
| 满意但不签施工 | 不退 + 补缴至¥12,800 | 不退，但无需补缴任何费用 |
| 不满意退出 | 无退出机制 | 修改N次后仍不满意→可终止，退部分订金 |
| 防补缴条款 | 无 | 禁止乙方以"未签施工"要求补缴 |

**谈判策略**：先拿订金版谈，谈不拢退到"订金不退但不补缴12,800"的底线。绝对要堵死"不签施工按原价收"条款。

合同生成脚本见 `scripts/generate-design-contract.py`，可直接修改参数生成不同版本。

## 第八阶段：婉拒与留底策略

当用户需要婉拒某装修公司、但想保留特定选项（如保留施工入口）时，话术策略不是"一刀切拒绝"，而是**按退回场景分层设计信息**。

### 核心逻辑

```
已签设计合同（事实不可改）    ≠    施工也未定（可以留口子）
                               ↓
话术告诉对方："设计方向基本定了"
  但不说死："施工这边还在考虑"
```

用户付了设计费但尚未签施工合同 — 此时所有被婉拒的公司理论上都是潜在的施工候选。一言说死会烧掉退路。

### 区分"全拒"与"留施工底"

| 场景 | 策略 | 关键信息 | 话术要点 |
|------|------|---------|----------|
| **彻底婉拒**（不再回找） | 明确收尾，给面子不留幻想 | "设计方向已经定了"、"签了设计合同" | 两句话交代完，不解释去哪家 |
| **留施工底**（备选施工入口） | 信息分层：设计定了但施工未定 | "设计方向基本定了，施工还在考虑" | 肯定对方已出的成果，为以后回头留过渡理由 |

### 留施工底的五条原则

1. **设计说"基本定了"，施工说"还在考虑"** — 不撒谎（确实签了设计合同），但不把施工的门关死
2. **主动权在己方** — 用"到时候我联系你"而非"你再问我"
3. **不解释去哪家了** — 对方追问就回"已经定了，谢谢关心"，不提供谈判弹药
4. **不给具体时间** — 不要说"下个月再联系你"，会变成对方追你的依据
5. **肯定对方已经出的成果** — 为后续真的回去谈施工留下自然理由（"你们布局图做得不错"）

### 常见坑

| 错误的说法 | 后果 |
|----------|------|
| "效果图比例不满意，但布局不错" | 对方会追着要求"再试一次效果图"，陷入无休止的修改拉锯 |
| "你们报价高了" | 对方立刻降价抛新方案，你得重新评估一遍 |
| "已经在别家签了" | 彻底关掉谈判空间，对方不再跟进——施工有变时也回不去了 |
| "下个月再联系你" | 下个月对方准时来问，你还没决定则被动 |

### 话术模板

**留施工底版**（用户想保留退路时用）：
> "布局图我认真看了，几个方案做得确实不错。目前设计方向基本定了，施工这边我们还在考虑，到时候再联系你。"

**彻底婉拒版**（确定不回找时用）：
> "感谢你们的服务，不过我们已经跟另一家签了设计合同了，就不再耽误你们时间了。后面有需要再联系。"

**为何有效**：这两条话术的共同点是**不给对方谈判空间**（不解释去哪家、不评价报价、不说"但是"）。留底版多了一句"施工还在考虑"，那是唯一的信息差，也是后续联系的自然接口。
