# Obsidian 文献矩阵库构建

## 触发条件

- 少帅下载了一批文献PDF，需要整理为结构化矩阵
- 需要为文献综述/基金申报准备文献基础
- 提到"文献矩阵""文献库""矩阵库""整理文献"

## 核心概念

文献矩阵库 ≠ 文献清单。矩阵库包含：**主矩阵表**（10列）+ **主题分类索引** + **期刊级别图例** + **GB/T 7714引用** + **方法统计** + **年份分布**。是文献综述的"施工图纸"。

## 目录架构

```
ObsidianVault\academia\文献库\
├── <大方向研究文献矩阵库>.md          # 总库（如"市场化环境治理"）
├── <大方向文献清单_GB7714>.md         # 纯引用清单
├── <子方向1>/                          # 如"碳排放权交易"
│   ├── <标题>-<作者>.pdf
│   └── _matrix_ingested.json           # 入库状态文件
├── <子方向2>/                          # 如"排污权交易"
│   ├── <标题>-<作者>.pdf
│   └── _matrix_ingested.json
└── _matrix_extract.json               # 临时提取数据
```

## 工作流（一次性建库 vs 每日增量）

### A. 首次建库（一次性）

```
步骤1: 提取PDF关键内容 → scripts/extract_pdf_matrix.py → _matrix_extract.json
步骤2: 人工/半自动分析 → 逐篇提炼方法/结论/期刊级别/主题分类
步骤3: 生成矩阵库 → scripts/gen_matrix.py → <大方向研究文献矩阵库.md>
步骤4: 补标题列 → gen_matrix.py默认无标题列，需Python脚本补
步骤5: 初始化状态 → scripts/matrix_ingest.py --init
步骤6: 验证 → 矩阵行数=PDF数，GB/T引用条目数=PDF数
```

### B. 每日增量入库（cron自动）

```\npw_download.py --max 10  →  下载新文献（⚠️ 2026.8.7 从18改为10，预留8篇额度给手动下载补充文献）\n      ↓\nmatrix_ingest.py          →  增量入库（去重，只处理新增）\n      ↓\n向少帅汇报新增X篇+累计Y篇+主题分布\n```

**matrix_ingest.py 用法**：
- `python matrix_ingest.py` — 正常增量入库
- `python matrix_ingest.py --init` — 首次部署：标记现有PDF为已入库
- `python matrix_ingest.py --dry-run` — 预览不写入

## 已知陷阱

### 陷阱1：标题标点差异导致去重失败
PDF文件名中 `_`（下划线）与矩阵库中 `——`（破折号）不一致，标题匹配去重会误判。**去重必须用 `_matrix_ingested.json` 状态文件**（记录完整文件名），不靠标题文本匹配。

### 陷阱2：gen_matrix.py 输出无标题列
`gen_matrix.py` 生成的主矩阵默认**不含标题列**（只有序号/作者/年份/期刊/卷期/级别/方法/结论/主题共9列）。需额外用Python脚本从title dict补充标题到第4列。

### 陷阱3：首次运行重复入库
状态文件 `_matrix_ingested.json` 不存在时，脚本会将矩阵库已有文献全部视为"新增"。**首次运行自动检测**：脚本检测到矩阵库有内容但状态文件为空→自动标记全部为已入库，不追加。

### 陷阱4：期刊识别需内置映射
新增文献的期刊名从PDF自动提取准确率低（中文PDF乱码）。需要在 `matrix_ingest.py` 的 `KNOWN_JOURNALS` 字典中维护**标题前缀→(期刊,年份,卷期)** 映射。首次建库时18篇映射硬编码；新增文献未命中时标注"未知期刊"，后续由LLM补充。

### 陷阱6：入库铁律——未知期刊/非CSSCI必须拒绝（2026.8.7 写死）⭐⭐
**少帅硬规则**：能入文献库的必须是 **SCI/SSCI/CSSCI/少帅本人论文**，入库规则写死在脚本里。

**历史bug（2026.8.7 实战发现）**：旧版 matrix_ingest.py 第275行**硬编码 `| CSSCI来源 |`** 标注——无论期刊是否验证，一律标CSSCI入库。导致"未知期刊"也入库、新闻稿/非CSSCI混入矩阵库（雷英杰新闻稿、冯振羽《国际金融》、任重《重庆交通大学学报》均被误入库）。

**修复后校验逻辑（已写死）**：
```python
from cssci_journals import is_cssci
AUTHOR_WHITELIST = ["冯泽宇"]  # 少帅本人论文豁免
for e in new_entries:
    if any(a in authors for a in AUTHOR_WHITELIST):
        e["level"] = "CSSCI扩展版（本人论文）"; 入库
    elif journal in ("未知期刊", "") or not is_cssci(journal):
        拒绝入库，打印拒绝记录
    else:
        e["level"] = "CSSCI来源"; 入库
```

**期刊验证三方式（未验证不入库）**：①PDF首页/页眉期刊名+卷期 ②PDF内嵌DOI查证期刊归属 ③CSSCI名单精确匹配（`is_cssci()`，禁止宽松子串匹配——旧版 `if name in j or j in name` 会把《国际金融》误判为《国际金融研究》、把"社会科学"字样误判所有学报，已改为严格匹配+变体归一化）。

**入库铁律配套动作**：
- 误入库的非CSSCI：从矩阵库删除对应行 + 从GB/T清单删除 + PDF移入 `_非CSSCI待清理/` 目录
- 清理后检查：矩阵库中"未知期刊"计数应为0（`grep -c "未知期刊"`）
- 新闻稿/报纸文章/非学术论文（如"双碳聚焦"栏目）一律不入库

### 陷阱5：cron prompt更新易误覆盖其他任务
用 `cronjob action=update` 更新某任务的prompt时，**必须先确认 job_id 对应的任务名**（`cronjob action=list` 查看），否则可能误覆盖其他任务（2026.8.6 实测两次误覆盖：CSSCI下载任务被写入GitHub日报prompt）。

## 实操案例

**2026.8.6 首次建库**：18篇碳交易CSSCI文献 → `碳交易研究文献矩阵库.md`（143行，6大主题分类）→ 升级为 `市场化环境治理研究文献矩阵库.md`（27篇：碳18+排污9，含"子方向"列+SSCI英文文献2篇）。

**排污权子方向扩展（2026.8.6 二次扩展）**：
- 排污权文献不全在 Obsidian 文献库——D盘毕业论文/考博资料目录（`毕业论文\排污权正在写\参考文献\`、`毕业论文\排污权抵押贷款\排污权抵押贷款参考文献\`、`1考博资料\博导邮件\`）有存量文献
- **筛选规则（少帅定义）**：非CSSCI不进库；本人硕士论文不进库；发表于CSSCI/扩展版的本人论文（如吴朝霞冯泽宇《产业经济评论》C扩）进库并标 ⭐少帅论文
- **期刊识别方法**：PDF首页"文章编号/ISSN/CN号"最可靠（如 `10.16868/j.cnki.1674-6252` → 《中国环境管理》）；PDF内嵌引用格式 `[J].环境科学与技术,2011,34(12H)` 直接给出期刊；无线索时用文献云其他镜像入口检索查证（见 cnki-paper-download 陷阱0c）

## 矩阵库的下游应用：为综述补充中文文献（2026.8.7 实战）⭐

矩阵库建好后，**常见下游任务是"为已有综述补中文文献"**（尤其基金申报综述，参考文献常全英文、中文为0）。流程：

1. **读综述**：识别各章节论点需求（如中国碳市场发展/省级特征/研究空白-行为异质性）+ 看数据完整性声明（"未获取：中文核心文献" = 明确补充信号）
2. **从矩阵库提取候选**：逐篇看 方法/结论/主题/期刊级别
3. **价值评估**：只选"直接支撑综述某章节论点 + 方法代表性 + 期刊级别高"的（分高/中/低三档），**宁缺毋滥不凑数**
4. **章节映射**：输出"综述章节→补充文献→价值"对照表，**经少帅确认后再改综述**
5. **执行**：GB/T 7714追加参考文献（原[1]-[34]后接[35]-[47]）+ 在对应论点处插引用 + 更新数据完整性声明

**关键教训（少帅纠正）**：**相邻领域可迁移借鉴**——"排污权就没有可以借鉴的吗？一样的污染品交易权"。同属排放权交易/污染品交易权的相邻子领域（如排污权→碳交易），其方法（DID/PSM-DID）、制度设计经验、市场机制结论可直接支撑本领域综述，**不要只盯本领域文献**。如涂正革(经济研究2015)的排污权波特效应检验方法→碳交易波特效应论证。

**排除逻辑示例（2026.8.7 碳交易综述）**：18篇碳交易文献选13篇，排除5篇——纯法学监管类（综述无监管章节）、税务会计类（与机制设计/行为/ABM核心无关）。
