# 学术论文写作执行器 (Academic Paper Composer)

## 概述

本技能提供从优化大纲到投稿级稿件的系统化写作框架，通过逐章和全文两级迭代质量控制，确保写作全程保持高质量。

**输入**: 详细、优化过的论文大纲（来自 academic-paper-strategist 或等效来源）

**输出**: 完整的投稿级稿件 + 质量验证报告

**前置条件**: 建议先使用 **academic-paper-strategist** 创建优化大纲（或提供等效的详细大纲）

---

## 何时使用

**写作阶段**:
- 系统化执行详细论文大纲
- 逐章撰写学术论文
- 写作过程中的质量控制
- 确保所有章节的一致性

**质量保证阶段**:
- 每章完成后验证
- 跨章一致性检查
- 最终质量评估
- 验证投稿就绪状态

**投稿准备阶段**:
- 准备平台投稿稿件
- 完成平台特定检查清单
- 生成最终投稿包

**触发词**:
- "从这个大纲写论文"
- "帮我写全文"
- "系统化执行大纲"
- "我有大纲了，帮我写论文"

## 工作流程

```
阶段四：系统化写作（逐章写作 + 质量门控）
    ↓
阶段五：质量控制（终审验证 + 投稿准备）
    ↓
输出：投稿级稿件 + 质量报告
```

**质量门控**: 每章完成后 + 全文终审

## 需要的输入

### 1. 优化的详细大纲（必需）

**要求结构**:
```markdown
## 摘要 (250-300词)
- [要覆盖的要点]

## 1. 引言 (1,500词)
### 1.1 问题提出 (400词)
- [内容指导]
### 1.2 文献综述 (600词)
- [要讨论的理论]
### 1.3 本文贡献 (500词)
- [具体主张]

## 2. [主体章节标题] (1,200词)
### 2.1 [小节] (400词)
- [论证结构]
- [关键引用]
...

## 参考文献
- [预期40-60篇来源]
```

**质量检查**: 大纲应包含：
- ✓ 章节标题和字数
- ✓ 三级小节结构
- ✓ 各节内容指导
- ✓ 关键引用
- ✓ 论证结构说明

### 2. 平台写作标准指南（推荐）
- 平台风格模式（语态、术语、引用格式）
- 结构规范
- 参考样本文献

### 3. 文献库（可选但推荐）
- 核心引用文献列表
- 研究空白分析
- 关键概念

## 阶段四：系统化写作

### 目标
逐章撰写完整稿件，配合迭代质量控制。

### 步骤4.1：写作环境准备

1. **验证大纲完整性**:
   - 所有章节已指定字数
   - 内容指导已提供
   - 论证结构清晰

2. **加载参考文档**:
   - 平台写作标准
   - 章节写作指南
   - 质量标准

3. **创建写作进度表**:
   ```markdown
   # 写作进度表
   - [ ] 摘要 (250词)
   - [ ] 第1章：引言 (1,500词)
   - [ ] 第2章：[标题] (1,200词)
   ...
   - [ ] 结论 (1,000词)
   - [ ] 参考文献
   ```

**决策点1**: 确认大纲和标准已加载，准备开始写作。

### 步骤4.2：逐章写作

**每章遵循以下序列**:

#### A. 写作前回顾

写第N章前：
1. **回顾本章大纲规范**: 字数目标、小节结构、内容指导、关键论证/引用
2. **回顾上一章**（如N>1）: 上一章最后一段、引入的关键概念、待兑现的承诺
3. **检查章节写作指南**: 加载对应模板

#### B. 写作执行

**内容原则**:
- **严格遵循大纲**: 尊重结构和字数
- **包含指定引用**: 使用大纲中的文献
- **保持平台风格**: 匹配语态和术语
- **使用章节模板**: 遵循对应指南

**质量目标（预防性）**:
- 论证质量：清晰论点、充分前提
- 引用质量：所有主张有支撑、格式正确
- 清晰度：精确表述、术语定义、良好过渡
- 结构：逻辑流畅、比例得当
- 风格一致：匹配平台规范

#### C. 写作后评估

完成章节草稿后，进行 **5维度评估**:

1. **论证质量** (1-4): 论点清晰？前提充分？反驳处理？
2. **引用质量** (1-4): 所有主张有引用？格式一致？关键文献覆盖？
3. **清晰度与可读性** (1-4): 表述清晰？术语定义？过渡顺畅？
4. **结构与流程** (1-4): 逻辑递进？比例得当？遵循大纲？
5. **平台一致性** (1-4): 风格匹配？语态一致？格式正确？

**质量门控4A**（每章完成后）:
- ✓ 总分 ≥16/20 (80%)
- ✓ 所有维度 ≥3/4（或已实施修订）
- ✓ 字数在目标±10%范围内

**未通过**: 在进入下一章前实施修订

#### D. 迭代（如需要）

如章节得分 <16/20：

1. **识别弱维度**: 哪些得分 <3/4？
2. **实施针对性修订**:
   - 论证质量问题 → 增加论证、处理反驳
   - 引用质量问题 → 增加支撑引用、修正格式
   - 清晰度问题 → 简化表述、增加定义、改善过渡
   - 结构问题 → 重组段落、调整比例
   - 风格问题 → 调整语态、术语、格式
3. **重新评估**: 生成新的质量报告
4. **重复直到通过**（通常1-2轮迭代）

**重要**: 当前章节未通过质量门控前，不进入下一章。

#### E. 章节完成

章节通过质量门控后：
1. 在进度表中标记完成
2. 保存章节和质量报告
3. 记录引入的关键概念（后续一致性检查用）
4. 预览下一章要求

**决策点2**（主要章节完成后）: 展示完成的章节摘要、质量评分，请用户决定：继续下一章 / 进一步修订 / 调整方法

### 步骤4.3：推荐写作顺序

1. **引言**（先写）— 建立论点和路线图
2. **主体章节**（按大纲顺序）— 逐章推进，每章质量检查
3. **结论**（主体完成后）— 综合发现，兑现引言承诺
4. **摘要**（最后写）— 总结完整论文
5. **参考文献**（全程编译）— 按平台标准格式化

### 步骤4.4：跨章一致性检查

所有章节写完后，终审前：

1. **术语一致性**: 提取各章关键术语，验证全文一致使用
2. **论证流**: 验证N+1章建立在N章基础上，引言路线图与执行匹配
3. **引用模式**: 检查引用分布是否均匀，关键文献在相关处引用

**输出**: 跨章一致性报告

### 步骤4.5：反向提纲检查（Reverse Outlining）⭐

**来源**：Master-cai/Research-Paper-Writing-Skills ★5,797（2026-08-05 借鉴引入）

**原理**：写完每节后，从成品反推结构，验证逻辑映射是否清晰。审稿人看不到作者的思考过程，只能看到文字本身是否自洽。

**执行**（每写完一个章节立即执行，不要等全文完成）：

1. **写下该节论点**（thesis/main claim）
2. **写下每个段落的主题句**（topic sentence）
3. **在每个段落下列出证据/解释点**
4. **检查映射**：
   - 主题句 → 论点：每段主题句是否支撑该节论点？
   - 证据 → 主题句：段内证据是否支撑该段主题句？
5. **修订或删除任何无法干净映射的段落**

**段落清晰度快速测试**（用户问"这段流畅吗"时用）：
- 这段有一个明确信息吗？
- 首句陈述了这段要做什么吗？
- 所有关键名词不需要隐藏上下文就能读懂吗？
- 每句与上句有清晰关系吗（因果/对比/后果/精化/举例）？

## 阶段五：质量控制

### 目标
执行全面终审评估，准备投稿级稿件。

### 步骤5.1：内容完整性检查

**学术修订硬规则（HARD RULES）** ⭐
**来源**：journal-adapt ★738 + paper2code ★1,468（2026-08-05 借鉴引入）

修订/润色任何稿件时，以下规则**凌驾于一切**：

1. **绝不添加事实**：不引入原稿没有的新经验主张、结果、引用或数据
2. **绝不改变技术内容**：公式、LaTeX命令、引用键、变量名、模型符号、数值结果、命题、脚注必须逐字保留
3. **绝不发明实现细节**（paper2code防幻觉）：论文未说明的细节不猜测补充——标注歧义让作者决定
4. **文献引用不转述**：读参考论文时只提取结构和修辞特征，不引用/转述/复现其发现（学术伦理）

**结构完整性**:
- [ ] 摘要 (250-300词)
- [ ] 引言包含所有必需要素
- [ ] 所有大纲中的主体章节存在
- [ ] 结论包含所有必需要素
- [ ] 参考文献格式正确

**内容完整性**:
- [ ] 引言中的所有承诺已兑现
- [ ] 所有主张有证据或论证支撑
- [ ] 所有技术术语已定义
- [ ] 所有反驳已处理
- [ ] 所有局限性已说明

**引用完整性**:
- [ ] 文中每个引用都有参考文献条目
- [ ] 每个参考文献条目都在文中被引用
- [ ] 引用格式全文一致
- [ ] 所有引用包含必要信息

### 步骤5.2：最终7维度评估

**7维度**（每项10分，总分70分）:

1. **总体论证质量** (1-10): 论点清晰度、章节整合、逻辑完整性
2. **文献整合** (1-10): 引用量、关键文献覆盖、引用整合、批判性参与
3. **清晰度与可读性** (1-10): 表述清晰、复杂概念解释、术语定义
4. **原创性与贡献** (1-10): 原创贡献、文献推进、重要性确立
5. **方法论严谨性** (1-10): 方法明确合理、一致应用、局限性说明
6. **结构与组织** (1-10): 逻辑流畅、组织最优、比例均衡、过渡无缝
7. **平台与风格一致性** (1-10): 风格匹配、格式正确、语态一致、引用完美

**质量门控5**（终审）:
- ✓ 总分 ≥56/70 (80%)
- ✓ 完整性清单100%完成
- ✓ 所有高优先级问题已解决

**未通过**: 实施修订后重新评估

### 步骤5.3：修订实施（如需要）

如终审得分 <56/70：
1. **优先排序**: 高优先（影响得分/完整性）→ 中优先（提升质量）→ 低优先（可选增强）
2. **系统化实施**: 先处理高优先，记录变更
3. **重新评估**: 生成新报告，验证≥56/70

**决策点3**: 终审后展示评分和就绪状态，请用户决定：立即投稿 / 实施可选改进 / 额外修订

### 步骤5.4：投稿包准备

1. **平台特定检查清单**:
   - **SCI期刊**: PDF/LaTeX格式、摘要字数限制、关键词、作者信息
   - **IEEE会议**: 双栏模板、页数限制、版权表格
   - **Nature系列**: 精简格式、亮点摘要、补充材料
   - **arXiv**: LaTeX/PDF、分类选择、无字体嵌入问题

2. **生成最终输出**:
   - 格式化稿件（PDF或LaTeX）
   - 摘要（单独文件）
   - 元数据文件
   - 投稿信（如需要）

3. **投稿前验证**: 重读全文、检查格式、验证链接/引用、校对

**输出**: 完整投稿包，可直接上传

## 完整输出文档

### 质量报告
1. **章节质量报告**（每章一份）— 5维度评分、通过/未通过、修订建议
2. **跨章一致性报告** — 术语一致性、论证流验证、引用分析
3. **最终评估报告** ⭐ — 7维度综合评估、完整性清单、投稿就绪决定

### 稿件文件
1. **完整稿件** ⭐ **主要交付物** — 所有章节整合、格式正确、引用完整
2. **摘要**（单独文件）— 独立250-300词
3. **元数据文档** — 标题、关键词、分类、作者信息

### 支撑文档
1. **写作进度表** — 所有章节完成、质量评分记录
2. **引用列表** — 所有参考文献、按平台格式化

## 常见问题

### 问题1：章节未通过质量门控
**症状**: 得分 <16/20
**解决**: 查看弱维度报告→实施针对性建议→重新评估（通常30-60分钟）

### 问题2：跨章风格不一致
**症状**: 某些章节语态/风格不同
**解决**: 运行跨章一致性检查→识别不一致→修订到主导风格

### 问题3：终审得分过低 (<56/70)
**症状**: 论文未通过终审质量门控
**解决**: 识别<7/10的弱维度→系统化实施高优先级修订→重新评估

### 问题4：完整性清单未完成
**症状**: 缺少必需元素
**解决**: 检查哪个类别有未完成项→补充缺失元素

## 最佳实践

1. **提供完整大纲**: 大纲越详细，写作质量越高
2. **信任迭代过程**: 逐章质量门控确保每节扎实
3. **在决策点积极参与**: 你的输入塑造最终稿件
4. **使用质量报告**: 章节报告显示具体弱点，终审报告提供客观评估
5. **遵循章节指南**: 写作前参考对应模板，预防问题
