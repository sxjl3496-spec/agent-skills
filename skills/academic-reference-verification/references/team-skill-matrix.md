## 三、已知短板与防范（血泪教训）

| Agent | 短板 | 防范 |
|---|---|---|
| Aion CLI | 曾编造文献卷期页码（曹辰编1-12实为165-173等16篇） | 文献类任务先装配验证技能；输出前自查；页码必须PDF/知网来源 |
| OpenCode | 综述引用13重复+7疑似编造+15处引用错位 | 引用新文献必须Crossref校验；编号先规划后引用 |
| OpenClaw | 无exec（跑不了团队CLI）；审核曾漏GB/T 7714卷期页码 | 汇报走文件回传；审核清单含"卷期页码逐条核对" |
| Claude Code | 长prompt截断；曾凭搜索摘要推断作者名（Yan&Yuan→Zhou&Zhao） | prompt写文件；作者名一律以Crossref family字段为准 |
| 主导者 | 曾把文献核实外包给无技能agent | 文献类任务亲办（少帅定） |

## 四、协作质量链

```
任务 → 主导者分解（对照本矩阵选人）
  → 执行者先装配科研技能包（涉文献时）
  → 执行 → 御史大夫审核（一票否决+评分卡）→ 返工
  → 主导者独立终审（亲自通读，不能只转述评审）→ 交付
```
