# 学术文献引用验证（Academic Reference Verification）

## 触发条件

- 用户要求核实/整理/检查参考文献（申报书、论文、综述的引用列表）
- 用户质疑"引用不标准""有残缺""文献是假的"
- 任何需要把文献条目写入交付物（申报书/论文/综述）的场景
- 团队协作中给其他 agent 分配文献任务前（需先装配本技能）

## 背景教训（2026-08-07 假文献危机）

湖南省自科申报书 52 篇参考文献中查出：**7篇疑似编造**（Crossref 查无此文）、
**30余处卷期页码错误**（Aion CLI"补全"的页码大量编造）、**3篇刊名错误**
（张冠李戴）。根源：无学术技能的 agent 凭记忆/二手元数据（OpenAlex）补全条目。
用户定性：**重大学术问题**——参考文献必须真实、GB/T 7714 完整、零残缺。

## 五条铁律（用户红线，违反即返工）

1. **禁止编造**：任何文献必须真实存在、可查证。查不到 → 删除或替换，绝不臆造
2. **禁止"待核实"**：最终交付物不允许出现"待核实/待补全"字样
3. **禁止残缺条目**：GB/T 7714 条目必须完整（作者. 题名. 刊名, 年, 卷(期): 页码.）
4. **双重验证**：英文文献经 Crossref 验证；中文文献从 PDF 原文/知网题录提取
5. **编号对应**：列表编号与正文引用一一对应，无悬空、无跳号

## 英文文献验证：Crossref API

### 方式1：按 DOI 精确验证（最可靠）

```python
import requests
session = requests.Session()
session.trust_env = False  # 必须：绕过系统代理
r = session.get(f"https://api.crossref.org/works/{doi}", timeout=20)
# 200=存在（用返回的 title/author/container-title/volume/issue/page 修正条目）
# 404=不存在 → 疑似编造，删除或替换
```

### 方式2：按标题+作者检索（无 DOI 时）

```python
r = session.get("https://api.crossref.org/works", params={
    "query.bibliographic": "论文标题关键词",
    "query.author": "作者姓",
    "rows": 3,
    "select": "DOI,title,author,container-title,volume,issue,page,published",
}, timeout=25)
```

### 判定规则

- 完全匹配 → 采用 Crossref 信息修正卷期页码（Crossref 是权威，覆盖申报条目）
- 无匹配 → **疑似编造**，删除或替换为真实文献
- 部分不符（卷号/页码不同）→ 以 Crossref 为准修正
- **作者名一律以 Crossref family 字段为准**——不要凭搜索摘要/网名推断（教训：太尉凭 WebSearch 摘要把 Yan&Yuan 写成 Zhou&Zhao）

### 常见坑

- 经典文献（Coase 1960 / Kahneman 1979 / Simon 1955）Crossref 收录不全 → 用公认标准信息：Coase, JLE, 1960, 3: 1-44；Kahneman, Econometrica, 1979, 47(2): 263-291；Simon, QJE, 1955, 69(1): 99-118
- 区分正式版与预印本（SSRN/arXiv 第一条常是预印本，第二条才是正式版——用 DOI 反查最稳）
- 中文期刊 Crossref 覆盖不全 → 中文文献走 PDF 验证
- 替换文献也必须 Crossref 验证（不能引入新的伪元数据）

## 中文文献验证：PDF 原文提取（PyMuPDF）

```python
import fitz  # PyMuPDF
doc = fitz.open(pdf_path)
p1 = doc[0].get_text()[:600]   # 首页：刊名/卷期/年份（"第X卷第X期"、"202X年X月"）
# 页码：页眉页脚数字，多种格式见下
words = doc[0].get_text("words")
h = doc[0].rect.height
bottom = [w[4] for w in words if w[1] > h - 70 and re.fullmatch(r"[0-9０-９]{1,4}", w[4].strip())]
```

### 页脚页码的5种格式（实战破解）

| 格式 | 示例 | 解读 |
|---|---|---|
| `·N·` | ·24· | 直接页码 |
| `-- N` | -- 110 | 页码（柯坚上海大学学报 1-14 即此格式） |
| 反序分列 | "７ １ １" = 117 | 个位/十位/百位分开显示（杨志安 116-124） |
| `X ７` 模式 | "１ ７" = 第1页 | 页内序+共X页（刘静一 70-76） |
| 文章编号 | 1004-8308(2024)01-0040-13 | 期01、起始页40、共13页 → 40-52 |

### 其他验证线索

- **"引用本文"格式行**：部分期刊首页自带规范引用（最可靠，如"何艳秋...资源科学, 2025, 47(12): 2681-2694"）
- **期刊首页标注**：`《西南民族大学学报》2024年第5期` 可纠正年份错误
- 无卷号期刊（科技管理研究/重庆社会科学/社会科学家等）→ 只标 `年(期): 页码`
- 增刊/合刊 → 标 `年, 卷(增刊): 页码`
- 网络首发 → `[J/OL]` 格式（需确认确实是网络首发，不能猜）

## GB/T 7714-2015 核心格式

| 类型 | 格式 |
|---|---|
| 期刊 [J] | 作者. 题名[J]. 刊名, 年, 卷(期): 起始-结束页. |
| 专著 [M] | 作者. 书名[M]. 出版地: 出版社, 年. |
| 章节 [M]// | 作者. 章节名[M]//书名. 出版地: 出版社, 年: 页码. |
| 会议 [C] | 作者. 题名[C]//论文集名. 会议地, 年: 页码. |
| 报告 [R] | 作者. 题名[R]. 出版地: 机构, 年. |

要点：作者≤3人全列，>3人列前3+", 等."（中文）/", et al."（英文）；英文姓全大写名取首字母；无卷号省略卷；电子资源用文章号（123469 形式）。

## 审核检查清单（10项）

1. 编号连续、无跳号、无重复
2. 正文引用与列表一一对应（无悬空引用、无列表未引）
3. 每篇有完整作者名（不允许"et al."代替全部作者）
4. 英文文献可经 Crossref/DOI 验证
5. 中文文献与 PDF 原文/知网题录一致
6. 卷/期/页码完整且正确
7. 刊名正确（警惕张冠李戴）
8. 年份正确
9. 无"待核实"字样
10. 引用位置与文献主题匹配（正文语境与该文献内容相符）

## 常见错误模式（识别清单）

- **编造页码**：凭记忆/推测补卷期页码（Aion CLI 案例：曹辰编 1-12 实为 165-173）
- **张冠李戴刊名**：综述元数据错（柯坚"中国人口·资源与环境"实为"上海大学学报(社科版)"；路梦瑶"系统工程理论与实践"实为"管理评论"）
- **无作者条目**：只有标题+期刊（OpenAI 生成条目的典型特征）
- **标题失真**：OpenAlex/二手元数据标题被改写（Rengs 标题、[29]-[33]卷号错误）
- **搜索摘要推断作者**：未 Crossref 实测就写作者名（太尉 Zhou&Zhao 案例）
- **重复引用**：同一文献两个编号（综述论文 13 组重复）
- **引用语境错位**：Q-learning 处引 LLM 论文、MSR 处引碳转移论文

## 引用语境验证（文献真实 ≠ 引用正确）⭐⭐

2026-08-07 丞相通读综述发现 4 处"文献真实但语境不匹配"——文献本身真实存在，但**用在错误的论证位置**，同样会被评审质疑：

| 案例 | 文献 | 被用于 | 问题 |
|---|---|---|---|
| [3] Heckbert 2010（生态经济学ABM综述） | "DID反事实/ABM+DID交叉验证"3处 | Heckbert 不讲 DID——DID语境应改引 DID 实证文献（如 Qi et al. 2021 JCP） |
| [10] Li et al. 2022（EPU对碳价影响） | "价格稳定机制（拍卖底价/价格天花板）" | Li 不讲价格稳定机制设计 |
| [13] Liu et al. 2025（电力企业MADDPG） | "为华菱钢铁设定高炉-转炉成本函数" | Liu 是电力企业模型，非钢铁 |
| [24] Wang et al. 2018（中国低碳转型综述） | "长株潭两型社会试验区" | Wang 是宏观综述，不讲湖南 |

**验证方法**：对每处正文引用，问"这篇文献真的讨论这句话的主题吗？"——尤其警惕：方法论文献被用于支撑具体行业/机制论断、综述文献被用于支撑具体政策/地区史实。修正方式：改引主题匹配的真实文献（须 Crossref 验证）或调整正文表述弱化指向。

## 多文档同步与 ±1 页码裁决 ⭐

**多文档同步**：同一文献可能出现在申报书/综述论文/文献综述主稿多个文档——修正一处后必须同步全部文档（本会话教训：申报书 V4.0 修正了页码，综述论文未同步，御史大夫终审打回）。交付前 grep 关键页码/作者名确认三处一致。

**±1 页码争议裁决**：多人分别提取页码可能差 ±1（如 214-223 vs 215-223，起始页是否计入）。裁决规则：**以 PDF 页码序列提取值为准**（连续序列的首尾值），而非个别页面观察值；双方争议时重新跑坐标级页脚提取，序列连续即定案。

**版本覆盖风险**：太尉修正后若不重新同步待审副本，审核方读旧版会误报"未修正"（本会话御史大夫案例）——每次修正后必须重新 cp 到审核方可读区并明确告知"新版已同步"。

## 批量核实流程（50篇级任务）

1. 提取文献列表（正则 `^\[(\d+)\]`）
2. 英文文献循环 Crossref 查询（query.bibliographic + query.author，rows=1-3）
3. 可疑条目（无匹配）单独精确检索或按 DOI 反查
4. 中文文献循环 PDF 提取（PyMuPDF：首页刊名 + 页脚页码）
5. 替换/修正条目，保持编号连续
6. 脚本校验：编号完整性 + 正文引用对应性（正则提取 `\[(\d+(?:[-,]\d+)*)\]` 与列表编号比对）
7. 输出 V 版本更新 + 核实记录（哪些替换、哪些修正）

## 数据声称实测复核（数值声称≠近似值）⭐⭐ 2026-08-07夜

**案例**：论文正文写"tidal intensity minimum 1.66, verified from the archived per-seed data"，丞相从实验记录 JSON 实测 90 次运行——**实际最小值为 1.6546**！"verified"声称与数据不符，审稿人复现即被抓。近似值（1.66）冒充精确验证值=数据真实性硬伤。

**纪律**：
1. 论文/报告中的数值声称（最小值/最大值/比率/显著性），必须从**原始数据文件实测复核**（读 JSON/CSV 算一遍），不能只信写作方自述
2. 四舍五入值用于表述可以，但**不得加"verified"声称**；精确值必须可复现（如"exceeds 1.65 in all 90 runs (minimum 1.655)"）
3. leader 终审时对关键数值做**抽样实测**（选 1-2 个声称值从原始数据验证），成本低、抓硬伤效率极高

## 写作层硬伤检查（复制粘贴/编号序列）⭐⭐

通读终审时专项检查（评审一眼能抓）：
- **重复段落/重复句**：同一句出现两次（实战：6.2 节"碳金融"句段中+段尾重复、3.5 节两阶段识别句重复）——grep 关键短语确认唯一性
- **编号序列错误**：First/Second/Third/**Fourth/Fourth**（两个 Fourth，第二个应为 Fifth）——检查枚举序号连续
- **声称-自审矛盾**：正文写"verified from data"但自审记录标"待验证"——两者必有一错，以实测为准
- **符号规范**：`1.70x`→`1.70×`、`t = -49.7`→`t = −49.7`（全稿统一负号）
